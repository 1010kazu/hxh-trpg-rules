# 用語集

| 用語 | 意味・参照先 |
|---|---|
| GM / NPC | GMは進行と世界を担当、NPCはGMが演じる人物。[はじめに](../rules/01-introduction.md) |
| PC | プレイヤーが担当する人物。[作成](../rules/03-character-creation.md) |
| 2D6 / 達成値 | 6面ダイス2個の合計／補正を加えた最終結果。[判定](../rules/02-checks.md) |
| 能力値 / 技能 | どのように行うか／何をするか。初期能力1～6、技能0～4 |
| 専門分野 | 具体的な詳しい分野。関連判定+2 |
| シーン / ラウンド / 手番 | 場面のまとまり／全員が動く区切り／1人が行動する機会 |
| リアクション | 自分の手番以外にも使える対応の回数。通常回避は消費しない |
| 念技術 | 念の熟練を表す値1～6、初期3。[念](../rules/04-nen.md) |
| 最大オーラ | 資源上限10+精神×3 |
| 現在オーラ | 自由に使用できる資源の点数 |
| 拘束オーラ | 持続発へ一時的に移した資源。解除・満了で返る |
| 段階 / 配分 | 攻撃・防御・その他への出力配分。資源消費とは別 |
| 発 | 自分で設計する固有能力。[作成](../rules/05-hatsu.md) |
| 強度 / 特殊性 | 効果の強力さ／通常ルールをどの程度飛び越えるか |
| 構築値 | 発を取得するために使う容量。使用時のオーラとは別 |
| 発容量 | 全発の構築値合計の上限。8+念技術+拡張 |
| 系統適性 | 自系統との関係による構築値への加算 |
| 発動条件 / 制約 | 使用前に必要な手順・条件／使える対象や場面を狭める制限 |
| 代償 / 誓約 | 使用に伴う不利益／破ると重大な結果を招く自分の約束 |
| 自然な応用 | 同じ能力原理から導ける使い方。追加構築値・成長点不要 |
| 命中差 | 命中達成値−回避達成値。威力補正の段階を決める |
| 打撃値・発威力 / 防護値 | ダメージ計算で比べる攻撃側／防御側の値 |
| 負傷値 | 1回の攻撃で生じる威力差。[負傷](../rules/08-equipment-and-recovery.md) |
| 負傷点 | 傷を蓄積する0～4の記録。負傷値とは別 |
| 瀕死・安定 / 危険 | ともに行動不能。危険は放置すると死亡し得る |
| 成長点 / 成長チェック | 成長に支払う持越可能な点／シナリオ末までの割引。[成長](../rules/09-advancement.md) |
| 暫定補足 Axx | 今回不足処理を埋めた試遊用の追加裁定。[台帳](../design/supplements.md) |
