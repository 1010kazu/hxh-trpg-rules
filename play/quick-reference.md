# 早見表

本文が定義元。以下は原文の暫定値と今回の[暫定補足](../design/supplements.md)を含む試遊用。原文の選択ルールは採用を卓で決める。

## 判定

| 内容 | 式・処理 |
|---|---|
| 基本 | 2D6+能力値+技能、または念技術 |
| 目標値 | 7簡単／9普通／11難しい／13かなり難しい／15達人級。以上で成功 |
| 対抗 | 高い側の勝ち、同値は受動・防御・現状維持側 |
| 6・6／1・1 | クリティカル／ファンブル。対抗では同種同士なら達成値比較 |
| 専門分野 | 関連判定+2、同時に複数でも1回 |
| 協力 | 具体的に手伝えば+1、人数によらず上限+1（A15） |

## 戦闘

1. 開始時：配置・配分を決め、2D6+俊敏で順番。同値は俊敏→1D6。
2. 手番開始：リアクション1へ、硬終了、堅の維持費1または終了。
3. 主行動1、補助行動1、移動1。自分の流1回は行動不要。
4. 宣言→対応→消費→命中→成立対抗（拘束・操作）→威力・負傷。
5. ラウンド終了：練終了。持続ラウンドは発動手番を含め数える。

| 内容 | 式 |
|---|---|
| 近接命中 | 身体または俊敏+格闘に2D6 |
| 射撃命中 | 俊敏または感覚+射撃に2D6 |
| 回避 | 俊敏+回避に2D6。通常回避はリアクション不要 |
| 通常近接の打撃値 | 身体+攻撃段階+武器等 |
| 発威力 | 攻撃強度+念技術、攻撃段階を加えない |
| 防護 | 身体+防御段階+防具等 |
| 負傷値 | 打撃値または発威力+命中差補正−防護 |
| 命中差1～2／3～4／5～6／7以上 | 威力+0／+1／+2／+3 |
| 攻撃クリティカル | 命中したなら威力補正最低+2 |
| 拘束成立 | 2D6+拘束強度+念技術 対 2D6+身体+念技術 |
| 操作成立 | 2D6+操作強度+念技術 対 2D6+精神+念技術 |

## 念・オーラ

| 技術 | 行動と処理 |
|---|---|
| 流 | 自分の手番1回行動不要、敵行動へはリアクション。1段階自動、2/3/4/5段階は俊敏+念技術で目標10/12/14/16。通常失敗1段階、ファンブル0 |
| 練 | 補助、資源2消費、1区分に+2段階、ラウンド末終了 |
| 堅 | 補助、開始2・次の手番から維持1、7段階・防御4以上 |
| 硬 | 主行動に付随、5/0/0、威力+2、次の自分の手番まで変更不可。周の+1と重複不可 |
| 隠 | 補助、その他1占有、配分と流を隠す |
| 凝 | 能動観察は主行動、隠への対抗は行動不要。感覚+念技術 対 精神+念技術 |
| 周 | 補助、物体ごとその他1占有、武器威力または防護+1 |
| 絶 | 補助、能動的念技術・持続発を終了、念の攻防を失う |
| 円 | 探索の索敵。自動戦闘補正なし、主行動で感覚+念技術 |

最大=10+精神×3。現在+拘束≦最大。消費は現在から失われ、拘束は現在から移動して解除・満了で返る。通常の配分5段階と資源点数は別。

## 負傷・回復・成長

| 負傷値 | 結果 | 加算負傷点 |
|---:|---|---:|
| 0以下 | 有効打なし | 0 |
| 1～2 | 軽傷 | 1 |
| 3～4 | 負傷 | 2 |
| 5～6 | 重傷 | 3 |
| 7～8 | 瀕死 | 4 |
| 9以上 | 致命傷 | 4・危険、致命的損傷を記録 |

負傷点合計は最大4。2は関連−1、3は身体・俊敏全般−1／部位直結−2、4は行動不能。初めて4で身体+2D6目標10の生存判定、成功安定・失敗危険。致命傷は判定せず危険。

医学は知性+医学+2D6目標10で安定化（戦闘中は主行動）。ファンブルは同じ人物から同じ瀕死者へ再試行不可。治療発は強度に応じた段階を扱い、通常1回1点回復。危険の安定化は別使用。

小休息10分：精神（絶なら精神+念技術）、同じ消耗へ連続不可。長休息：安全な数時間で現在を最大−拘束まで。

成長は基本3+成果0～2。チェック1つで能力値または技能の費用−1、割引最低0。未使用チェックは消滅、成長点は持越可。
