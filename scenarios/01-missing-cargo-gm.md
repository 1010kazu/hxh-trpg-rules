# 「消えた医療便」：GM用・秘密あり

[プレイヤー向け導入](01-missing-cargo-player.md)だけを最初に全員へ共有する。以下はGM用。

## 準備と全体像

想定はPC3人、サンプルPC利用、会話とルール確認込みで2～3時間程度（未計測）。[基本判定](../rules/02-checks.md)、[念](../rules/04-nen.md)、[戦闘](../rules/07-combat.md)、[回復](../rules/08-equipment-and-recovery.md)を手元に置く。

運び屋レンは借金を抱え、薬を倉庫番ダンへ渡す約束をしてしまった。ダンはレンの妹の治療費を出しており、薬を横流しして穴埋めしようとしている。ただしダンは本当は妹や診療所の患者を傷つけたくない。薬は倉庫3号に無事に保管され、レンは拘束されているが無傷。

ダンの仲間エダは放出系能力者。ダンが倉庫の警報盤を鳴らせば戦うが、ダンが和解すれば従う。プレイヤーの発言を潰すために戦闘を強制しない。倒す以外に、借金の証拠を集めて業者に仲介してもらう、妹の医療支援を約束する、潜入してケースとレンを救出する、といった解決がある。

戦闘の有無によらず、念の条件を観察し、安全な手段を考える機会を用意する。成長点は基本3、薬を届ければ+1、レンの救出と返済・医療の支援に道筋をつければ+1（最大5）。

## 場面1：依頼を聞く

依頼主は輸送業者の所長サワ。薬の行き先、運び屋の特徴、最後の場所は質問に答えて必ず渡す。詳しく調べるなら知性+調査9。成功で保冷ケースの記録から「第3倉庫で一度開閉」が判明。失敗でも荷揚げ場に進める。

交渉9で業者の協力を求めれば、返済相談や診療所の紹介が可能だと分かる。判定をせず事情を説明しても、無理のない支援なら引き受ける。所長は犯人へ薬を売る約束はしない。

## 場面2：荷揚げ場で調査

調べると第3倉庫へ向かった台車の跡が見つかる。これは必須情報なので失敗で消さない。

| 手段 | 判定 | 成功で分かる追加情報 |
|---|---|---|
| 荷札・足跡 | 感覚+観察または追跡9 | 荷物とレンが一緒に運ばれた。血痕なし |
| 作業員への聞き込み | 社交+交渉9 | ダンが妹の治療費で困っていた |
| 念の痕跡 | 感覚+念技術11（能動的な凝） | 粘着性の札が扉にあり、外すと力が消える |
| 通信履歴 | 知性+電子11 | ダンとレンのやり取り、薬を横流しする前の保管予定 |

1つ失敗するたびに見回りに気づかれ、次の倉庫接近は正面で声をかけられる。同じ手段の振り直しだけでは再挑戦不可。別の手段なら追加情報を取りに行ける。先へ進むことは妨げない。

## 場面3：倉庫に接近

倉庫は「外の荷場」「室内入口」「棚の奥」の3区画。各区画内と隣接区画間は近距離、荷場から棚の奥は中距離。隣区画へ移るには通常移動+主行動。入口から棚の奥は見通せるが、棚は半遮蔽で回避+2。棚裏へ隠れると直接射撃不可。ケースとレンは棚の奥、ダンは入口、エダは棚の奥にいる。

入口の柱に「留め札」が貼られ、オーラの帯が床を走る。隠は使用していないので配分と帯は公開する。感覚+観察9で札に近づくたび帯が張る様子、凝なら判定不要で「帯と札がつながっている」ことを見せる。札を剥がせば拘束できなくなると推測できる。隠してから急に発動条件を追加しない。

会話ではダンが「患者を傷つけるつもりはなかった」と話す。妹への治療協力と返済の相談を具体的に提示すれば社交+交渉9で協力を得る。説得材料なしなら11。失敗しても攻撃を即発生させず「支援を保証できる人物へ連絡してくれ」と条件を返す。本人の利益を無視した自白や無条件降伏は交渉だけで強制しない。

潜入なら隠密とダンの感覚3+察知2の対抗。成功で入口の札を先に剥がす、あるいはレンの所まで移ることができる。失敗したら声をかけられて会話または戦闘へ。無防備な相手への自動致命傷は与えない。

## 場面4：対決（必要な場合）

戦闘開始時に配分を公開し、全員2D6+俊敏で順番を決める。ダンはまず拘束で侵入を止め、エダはまず安全な空所への威嚇射撃を主行動と実射程の消費で行い、その後の手番から攻撃する。威嚇だけで相手への数値ペナルティは生じない。1人を瀕死まで集中攻撃し続ける行動は取らず、PCが降参や搬送を申し出たら応じる。これはNPCの動機であり攻撃の数値を密かに変える指示ではない。

PCは薬の回収、レン救出、札の除去、交渉を主行動として選べる。戦闘中にケースをつかむ・レンの縄をほどく・札を剥がすのは接触地点で主行動、妨害者がいなければ判定不要。妨害者が目の前にいれば身体+運動 対 相手の身体+運動、札を剥がすなら俊敏+手先 対 ダンの俊敏+手先も選べる。この場面の物品取得の裁定であり、全発の解除に同じ判定を使うわけではない。

<a id="gm-dan"></a>

### ダン（具現化系）

| 項目 | 数値 |
|---|---|
| 能力値 | 身体3、俊敏3、感覚3、知性3、精神3、社交3 |
| 技能 | 格闘2、回避2、手先2、察知2、運動2、交渉2。他0 |
| 念技術・資源 | 念技術3、最大19、開始時現在14・拘束3（発動消費2支払済み）、発容量11 |
| 初期配分・装備 | 攻撃2/防御2/その他1、標準武器+1・軽防具+1 |
| 判定 | 行動順+3、近接+5、回避+5、発命中+6 |
| 威力・防護 | 通常打撃6、防護6 |
| 負傷 | 初期0。3で降参、レンや薬の安全が保証されれば戦闘前でも和解 |

**発「留め札」**：具現化した札から帯を伸ばして捕らえる。主効果拘束3+近距離1+単体0+1シーン2+特殊性0+具現化適性0=構築値6。札と帯の生成はこの拘束原理を実現するための表現であり、独立した万能道具生成機能は持たない。柱に札を貼るのが発動条件（軽い条件、値引きなし）。

待機時に基本値4から発動消費2とシーンの持続確保3を処理し、戦闘開始時は現在14・拘束3。帯は手の届く位置の札から近距離まで、単体だけを捕らえる。命中は感覚3+念技術3、成立は拘束3+念技術3 対 身体+念技術。移動不可と身体・俊敏の身体行動−1、発は使用可。脱出は主行動で同じ成立対抗、成功で解除。

札が貼られた状態は発の待機状態。相手を捕らえるのはダンの主行動と反復消費3を使い、この発につき1ラウンド1回まで。外れたら発を解除して拘束3を返すが、発動消費と反復消費は戻らない。張り直しは接触して主行動。1つの札で同時1対象、別対象を捕らえるなら解除して再使用（新たに発動2を消費し、成立条件を満たして3拘束）。札を剥がすか破る、ダンが任意解除する、場面が終わると帯も消え、拘束返還。札は普通の紙程度、妨害なく接触できれば破れる。柱の札を遠隔で狙う場合、固定物として能動回避なし、標準の命中差補正+0。小さな札への精密射撃は目標値11を事前提示し、命中して威力1以上なら普通の紙の札は破れる。これは留め札固有の破壊条件。

<a id="gm-eda"></a>

### エダ（放出系）

| 項目 | 数値 |
|---|---|
| 能力値 | 身体3、俊敏3、感覚4、知性2、精神3、社交2 |
| 技能 | 回避2、観察2、察知2、格闘1。他0 |
| 念技術・資源 | 念技術3、最大19、現在19・拘束0、容量11 |
| 初期配分・装備 | 攻撃2/防御2/その他1、軽防具+1、素手 |
| 判定 | 行動順+3、発命中+7、回避+5 |
| 威力・防護 | 発威力6、防護6 |
| 負傷 | 初期0。負傷点2で撤退を提案、ダンの降参で攻撃停止 |

**発「圧縮弾」**：攻撃3+中距離2+単体0+持続0+特殊性0+放出適性0=構築値5。主行動、感覚4+念技術3で回避と対抗、威力6。消費は中距離5、近距離4、接触3。外れても消費。制約なし、その他枠なし、維持なし。軌道は公開、追尾なし。現在不足なら使えず、回避して撤退する。通常攻撃や攻撃段階を威力に足さない。

### 人数の調整

PC2人ならエダは戦闘に参加させず連絡役にする。PC1人または4人以上はこの導入の検証対象外。GMは人数に合わせた構成を事前に相談し、初回は3人を推奨する。

## 場面5：回収と治療

レンの縄は念ではなく普通のロープ。解放すれば歩ける。薬はまだ使用可能。PCが無傷なら治療を強制せず、短い小休息と資源の記録方法だけ確認する。傷があれば医学・治療発を使用し、瀕死なら安定化と医療搬送を優先する。瀕死・危険のまま薬の締切を理由に放置させない。

全員が薬とともに診療所へ戻れば主要目的達成。ケースを取り逃がしてもレンを救い次の手掛かりを得る結末にできる。失敗しても基本成長点3は得る。

## 終了処理と記録

成果に応じ3～5成長点を配る。クリティカル・ファンブルのチェックがどの項目についたか確認し、使うなら費用から引いて消去する。未使用成長点を持ち越し、未使用チェックは消す。[成長](../rules/09-advancement.md)の例を使う。

各PCの消費・拘束返還・負傷、戦闘ラウンド数、推測できた能力条件、迷った裁定を記録する。実卓後は[調整課題](../design/open-questions.md)へ反映する。
