# 第8章 装備・負傷・回復

この章の装備数値、自動射撃、負傷値表、回復量は原文から続くテスト対象。武器を持つことだけで念能力者への命中や突破が保証されるわけではない。

## 暫定補足による負傷と回復

<a id="a19"></a>

**暫定補足 A19：負傷点と部位。** 命中・防護後の負傷値0以下は有効打なし。1～8では軽傷1・負傷2・重傷3・瀕死4を累積し、上限4とする。有効打の描写から部位をGMと記録する。部位別の負傷点や部位狙いの追加補正は設けない。

3点以下から4点へ到達した瞬間に2D6＋身体、目標値10で生存判定1回。成功は瀕死・安定、失敗は瀕死・危険。到達前の負傷補正を生存判定に持ち込まない。4点への追加有効打は危険へ移行し、再判定しない。治療で3点以下へ戻った後の再到達は新たな瀕死として判定する。負傷値9以上は元の点数を問わず4・危険・致命的損傷ありとし、生存判定を省略する。明らかに生存不能な状況はGMが先に結果を説明する。

補正は現在の累積段階と、まだ治っていない傷が動作に直接関係するかで決める。負傷分は最も強い1つだけを適用する。複数部位や重傷の一般−1と部位直結−2を合算しない。他原因の拘束・装備補正は条件を満たせば適用する。治療で段階が下がれば直ちに新段階を使い、治った傷は治療内容に従って記録する。負傷補正は判定に適用し、威力・防護・能力値・派生値・決定済み行動順・行動回数を自動で変えない。

<a id="a20"></a>

**暫定補足 A20：治療と休息の境界。** 負傷点1/2/3/4は軽傷/負傷/重傷/瀕死に対応。医学で十分な治療をするには安全な場所で1時間程度とし、目標値10、1人につき長休息ごとに1回まで、成功で1点回復。十分な治療の試行は対象単位の回数として管理し、治療者を替えて追加しない。普通の失敗でも試行回数を使う。救命の安定化と十分な治療による回復機会は別に管理する。危険状態や致命的損傷は先に対応する。自然治癒の目安を満たしたら負傷点を1段階減らし、まだ残る傷は新しい段階の期間を改めて待つ。休息でのオーラ回復は最大−拘束まで。小休息の使用済みは記録し、同じ消耗では繰り返さない。長休息でリセットする。連続小休息のためだけの無意味な発使用は新しい消耗と扱わない。

<a id="a21"></a>

**暫定補足 A21：治療発の結果。** 強度1は負傷点を減らさず止血・痛み軽減。強度2以上は対象の現在段階を治療できる場合だけ1点回復する。危険の安定化は回復と別の1回。致命的損傷は強度5で安定化できるが、通常治療で負傷点だけを下げて治した扱いにせず、強度6の治療や適切な医療へつなぐ。強度6も通常1回1点とし、欠損等の回復内容は発の設計時にGMと合意する。消費した治療オーラは持続を解除しても返らない。

<a id="a22"></a>

**暫定補足 A22：弾薬と射程。** 導入用の抽象管理では通常弾薬を細かく数えず、自動射撃のたびに「弾薬消耗」を1つ記録。3つ目の自動射撃を解決した後にその武器は弾切れとなり、通常・自動とも再装填まで使用できない。携行予備弾があれば補助行動で再装填して0に戻す。導入では予備弾1回分。拳銃・SMG・弓・ショットガンは近距離、ライフル・クロスボウは中距離、高威力ライフルは長距離を基準有効射程とする。ショットガンは中距離にも威力5で届き、この区分までは射程超過−2を適用しない。自動射撃の威力補正は通常の命中差補正から1段階（+1）増やし、上限+3。攻撃クリティカルの最低+2を適用してから増やす。通常射撃だけの弾数を省略する導入用の管理方式である。弾数を数える方式を使う卓はセッション前に管理方法を合意する。自動射撃で対象数・回避回数を自動で増やさず、手加減の上限は最後に適用する。

## 治療と資源の例

負傷点3（重傷）へ強度3治療は使えない。強度4なら接触単体の消費5で3→2。次は強度3・消費4で2→1、さらに強度2・消費3で1→0。常に強度4で治療してもよいが毎回5を消費する。

瀕死・危険（4）へ強度5を1回（消費6）で安定化、もう1回（消費6）で4→3。致命的損傷ありなら後者だけで完全治療にはならない。医学の安定化は知性+医学の目標値10、戦闘中は主行動。医学ファンブルならその治療者は同じ瀕死状態の対象へ再試行不可、別人は試せる。

最大22・拘束4・現在2で絶を使わず小休息すると、精神4なら現在6・拘束4。長休息では現在18まで。拘束を解除して現在22になり、二重に回復しない。

## 武器・防具 暫定案

出典：Ver.0.2 第33節。

#### 近接武器

素手：+0

軽武器：
+0威力。
隠しやすい、投擲可能、狭所で使いやすい等の特徴を持つ。

標準武器：
威力+1。

大型武器：
威力+2。
命中判定-1。この低下は命中差にも反映する。

#### 防具

軽装・防具なし：
+0。

軽防具：
防護値+1。

重防具：
防護値+2。
俊敏系判定-1。回避、俊敏を使う攻撃、判定が必要な流、開戦時の行動順判定に適用する。素の俊敏値と決定済み行動順は変えない。1段階の自動の流は判定不要。身体・感覚等の判定へは広げない。装備区分の防護値は1つだけを使い、重ね着で加算しない。

数値は要テスト。


<a id="sec-34"></a>

## 射撃武器 暫定案

出典：Ver.0.2 第34節。

射撃武器は身体値を威力へ加えない。

**射撃威力＝武器固有威力＋命中差補正**

防護値：

**身体＋防御オーラ＋防具**

通常の銃弾には攻撃オーラを加算しない。

銃そのものへ周を使用しても、通常は発射後の弾丸へ念は残らない。

弾丸へ念を維持・付与する場合は、放出系などを利用した専用の発を必要とする。

#### 暫定武器威力

| 武器 | 威力 |
|---|---:|
| 小型拳銃 | 4 |
| 拳銃 | 5 |
| 大型拳銃 | 6 |
| SMG | 5 |
| ライフル | 6 |
| 高威力ライフル | 7 |
| ショットガン近距離 | 7 |
| ショットガン中距離 | 5 |
| 弓 | 4 |
| クロスボウ | 5 |

有効射程を超える射撃は、暫定で命中-2程度。

遮蔽：

- 半遮蔽：回避+2程度
- ほぼ完全な遮蔽：直接射撃不可

#### 投擲武器

投擲は使用者の身体能力が直接影響するため、身体＋攻撃オーラ＋武器補正を使用可能。

#### 自動射撃

以下を暫定候補とし、要テスト。

- 自動射撃可能な武器のみ
- 主行動で宣言
- 命中判定-1
- 命中した場合、命中差による威力補正を1段階上昇
- 自動射撃1回につき弾薬消耗1を記録し、3で弾切れ。補助行動と予備で再装填

| 0以下 | 有効打なし |
| 1～2 | 軽傷 |

| 5～6 | 重傷 |

<a id="sec-36"></a>

## 負傷点

出典：Ver.0.2 第36節。

内部的に負傷点として蓄積する。

- 軽傷＝1
- 負傷＝2
- 重傷＝3
- 瀕死＝4

例：

軽傷＋軽傷＝負傷

負傷＋軽傷＝重傷

負傷＋負傷＝瀕死


<a id="sec-37"></a>

## 負傷ペナルティ

出典：Ver.0.2 第37節。

#### 無傷

なし。

#### 軽傷

なし。

#### 負傷

負傷内容に明確に関係する判定へ**-1**。

例：

腕の負傷：
格闘、射撃、手先など。

脚の負傷：
運動、回避など。

#### 重傷

身体・俊敏を使用する判定全般へ**-1**。

負傷部位へ直接関係する判定は使用能力値にかかわらず**-2**を使う。一般の−1とは重ねない。知性の調査、腕を使わない感覚＋念技術の発、交渉など、傷と直接関係しない判定は補正なし。適用は判定前に提示する。

#### 瀕死

原則行動不能。

GMは傷の内容に応じて、個別の状況的ペナルティを設定してよい。


<a id="sec-38"></a>

## 瀕死

出典：Ver.0.2 第38節。

負傷点4に達すると瀕死。

原則行動不能。

瀕死になった瞬間、一度だけ、

**2D6＋身体 vs 10**

で生存判定を行う。

#### 成功

**瀕死・安定**

自然には悪化しない。

ただし瀕死・行動不能のまま。

#### 失敗

**瀕死・危険**

適切な処置が行われないまま十分な時間が経過した場合、死亡する。

何ラウンドで死亡するかを細かく固定せず、戦闘終了・放置時間・状況などからGMが判断する。

#### 致命傷

負傷値9以上の致命傷を受けた場合、生存判定を行わず、最初から**瀕死・危険**となる。


<a id="sec-39"></a>

## 医学

出典：Ver.0.2 第39節。

瀕死・危険のキャラクターへ応急処置を行う場合、

**2D6＋知性＋医学 vs 10**

成功すると、

**瀕死・危険 → 瀕死・安定**

となる。

すでに安定している瀕死者に、応急処置判定を行う必要はない。

戦闘中の応急処置は主行動。

#### 医学ファンブル

応急処置失敗。

その治療者は、同じ瀕死状態にある対象へ再度応急処置を試みることができない。普通の失敗なら次の主行動で再試行できる。治療で負傷点3以下へ戻ってから再び瀕死となった場合は、新しい瀕死状態として扱う。

別の人物は試行可能。医学の安定化の成功だけでは負傷点4のままで、安定4→3にも強度5の治療発または十分な医学治療が必要。

#### 安全な場所での治療

十分な時間と環境がある場合、医学判定成功で負傷点1点を回復。

同じ場所で連続して判定を繰り返して全快させることはできない。

安全な1時間程度の十分な治療は目標値10、対象1人につき長休息ごとに1試行、成功で1点回復する。試行回数は対象単位で、治療者を替えて増やさない。普通の失敗でも回数を使う。


<a id="sec-40"></a>

## 医療設備

出典：Ver.0.2 第40節。

医療キット：
医学判定+1。

本格的な病院・医療設備：
医学判定+2程度。

または通常では治療できない負傷を治療可能。

瀕死の安定化自体は、医療キットなしでも試行可能。

## 自然治癒

出典：Ver.0.2 第41節。

目安：

- 軽傷：一晩
- 負傷：数日
- 重傷：1週間以上
- 瀕死：医療必須

細かな日数管理より、シナリオ進行に応じて処理してよい。


<a id="sec-44"></a>

## オーラ回復

出典：Ver.0.2 第44節。

戦闘中の自然回復はない。

#### 通常小休息

10分程度、安全な場所で休息。

**精神点**の現在オーラを回復。

#### 絶による小休息

10分程度、安全な場所で絶を維持して休息。

**精神＋念技術点**の現在オーラを回復。

絶の間は念防御・念による警戒をほぼ失う。

#### 連続休息

同じ消耗への小休息は1回。通常小休息から絶へ切り替えて同じ消耗へ回復を追加しない。絶の切替に伴う解除・拘束返還を済ませてから、最大−拘束まで回復する。

戦闘、大きな発使用、長時間の探索など、新しい消耗が発生した後であれば再度使用可能。

#### 長休息

数時間、安全な場所で十分に休息。

現在オーラを最大−拘束まで回復。

拘束中のオーラは、発を解除しない限り戻らない。


<a id="sec-45"></a>

## 現在オーラ0

出典：Ver.0.2 第45節。

即座に気絶はしない。

ただし、

- 新たな発使用不可
- 新たな練・堅・硬など高出力技術使用不可
- 念関連行動に大きな制限

を受ける。

最後の点を支払って成立した練・堅は、その支払いで得た期間まで有効。堅の次の維持時点で不足すれば終了する。既存の持続発も現在0だけでは自動終了せず、有料反復は実行できない。

負傷などを支払ってオーラ不足を補う「限界使用」は採用しない。
