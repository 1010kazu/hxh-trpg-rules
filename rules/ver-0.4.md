## 第1章 はじめに

この章を読んだら[基本判定](02-checks.md)へ進む。参加者は原作の基本的な念の知識があることを前提とする。

### 遊ぶ準備

TRPGは、会話で架空の人物の行動を決め、成否が不確かな場面をサイコロで解決する遊び。GM（ゲームマスター）は世界・事件・NPCを担当し、プレイヤーはPC（プレイヤーキャラクター）を1人ずつ担当する。勝敗を競う役割分担ではない。

6面ダイス2個（ダイスアプリ可）、本書、筆記具、[キャラクターシート](../play/character-sheet.md)、[発シート](../play/hatsu-sheet.md)を用意する。導入シナリオはGM1人とプレイヤー3人を基準にする。初回はサンプルPCで始めてもよい。

GMは場所と出来事を説明し、プレイヤーは「何を、どうしたいか」を伝える。GMは結果を伝えるか、判定方法と失敗した場合の影響を説明する。判定後は結果を物語に反映して次の行動へ進む。調査や交渉もこの繰り返しである。

<a id="01-introduction-a01"></a>

**暫定補足 A01：時間単位。** シーンは同じ目的・場所を扱うひとまとまり。場面の区切りをGMが宣言する。ラウンドは戦闘で全員が1回ずつ手番を得る区切りであり、秒数は固定しない。「1シーン」はGMが区切りを宣言するまで続く。

最初にPC同士が協力する理由、遊べる時間、扱いたくない描写を相談する。進行中でも描写を省略・変更してよい。原作の人物や出来事を詳しく再現する必要はない。

<a id="01-introduction-sec-1"></a>

### ゲーム概要

出典：Ver.0.2 第1節。

本作は、『HUNTER×HUNTER』の世界観をベースにしたTRPGである。

プレイヤーキャラクターは原則として、すでに念を習得している念能力者として作成する。ハンター試験や念習得そのものをゲームの基本進行とはしない。

ゲームの中心は、

- 依頼
- 探索
- 調査
- 交渉
- 戦闘
- 冒険
- 念能力による問題解決

である。

基本的なファンタジーTRPGの構造に、自由度の高い念能力を組み合わせる。

念能力戦では、

- 相手の能力を読む
- オーラ配分を読む
- 条件や制約を推測する
- 相手の隙を作る
- 自分の能力の情報を隠す
- 能力の応用方法を考える

といった情報戦・読み合いを重視する。


<a id="01-introduction-sec-55"></a>

### Ver.0.2の設計思想

出典：Ver.0.2 第55節。

このTRPGでは、

**強い念能力を持っている者が自動的に勝つ**

ことを目指さない。

通常技能、専門知識、戦術、情報、オーラ管理、発の相性、制約の把握によって状況を覆せるゲームを目指す。

念能力は、魔法リストから選択するものではなく、自分自身で設計する。

自由な能力だからこそ、強力な能力には強力である理由を必要とする。

一方で、

**能力を柔軟に使う発想そのものにはペナルティを与えない。**

同じ能力原理から自然に導ける応用は自由とし、プレイヤーが能力の新しい使い方を考えることを推奨する。

発容量は、キャラクターが念能力へ割ける「メモリ」として扱う。

シンプルな発を複数取得することも、一つの複雑・特殊な発へ大半のメモリを使用することもできる。

不得意系統を使用すること自体は禁止しない。

その代わり、系統相性の悪い能力ほど多くの発容量を消費する。

制約・代償・誓約は構築値の割引ではなく、

**通常では成立しない性能を成立させる理由**

として扱う。

そして念能力戦では、

**相手の能力を理解することそのものが戦闘力になる**

ことを、本システムの大きな特徴とする。

## 第2章 基本判定

判定ではダイス2個の合計を出し、指定された能力値と技能などを加える。通常の目標値判定は目標値以上で成功。対抗判定では相手より高い値が必要である。

<a id="02-checks-a02"></a>

**暫定補足 A02：補正の適用。** 同じ判定に複数の専門分野が当てはまっても専門分野の+2は1回のみ。医療キットと病院など同じ用途の設備補正は高い方のみ。異なる理由の補正は加算し、GMは振る前に採用する組み合わせを伝える。

### 技能の使い分け

以下は適用例であり、能力値との組み合わせを固定しない。

| 技能 | 主な用途 |
|---|---|
| 格闘 | 素手・近接武器の攻撃 |
| 運動 | 登攀、跳躍、水泳、走行 |
| 耐久 | 疲労や厳しい環境への持久 |
| 回避 | 攻撃をかわす |
| 射撃 | 銃、弓、投擲の照準 |
| 隠密 | 姿や物音を隠す |
| 手先 | 鍵、細工、精密作業 |
| 観察 | 目の前の具体的な手掛かりを見る |
| 追跡 | 足跡や移動経路をたどる |
| 察知 | 不意の危険や周囲の気配に気づく |
| 調査 | 資料や証言を集めて整理する |
| 医学 | 応急処置、診断、治療 |
| 機械 | 機械の点検、修理 |
| 電子 | 電子機器、通信、情報端末 |
| 知識 | 学術・地域などの知識を思い出す |
| 集中 | 雑念や妨害の中で作業を続ける |
| 看破 | 隠された意図、矛盾、偽装を見抜く |
| 交渉 | 条件や利害をすり合わせる |
| 威圧 | 圧力をかけて要求を通す |
| 欺瞞 | 嘘や偽装を成立させる |
| 心理 | 感情や動機を理解する |

看破は「嘘を見抜く」、心理は「なぜそう思うかを理解する」の目安。迷う場合は行動目的に近い技能をGMが選ぶ。未取得技能は0として使用する。

### 計算例

感覚4・観察3で、出目が3と4なら達成値14。専門分野「古代遺跡」が該当すれば16。目標値11の遺跡の罠探しは成功する。

攻撃側と回避側がともに14なら回避成功。攻撃側が6・6、回避側が通常の出目なら、達成値の大小にかかわらず攻撃側が勝つ。両者6・6なら通常どおり最終達成値を比べ、同値は回避側の勝利。

<a id="02-checks-a03"></a>

**暫定補足 A03：攻撃の特殊出目の優先順位。** 対抗結果を先に決める。「自動命中」は通常結果に対する扱いであり、相手もクリティカルなら対抗判定の比較に従う。命中したクリティカルの命中差が0以下でも威力補正は最低+2。「攻撃ファンブルは失敗」も通常結果以上の相手に対する記述として扱い、双方ファンブルなら対抗規則の達成値比較を優先する。攻撃側が勝った場合はその命中差を使う。これは原文内の競合を解消する暫定裁定である。

<a id="02-checks-sec-2"></a>

### 基本判定

出典：Ver.0.2 第2節。

基本判定は、

**2D6＋能力値＋技能**

念技術そのものを扱う場合は、

**2D6＋能力値＋念技術**

を基本とする。

##### 目標値

| 目標値 | 難易度 |
|---:|---|
| 7 | 簡単 |
| 9 | 普通 |
| 11 | 難しい |
| 13 | かなり難しい |
| 15 | 達人級 |

##### 対抗判定

双方が判定し、高い方が勝利する。

**同値の場合は、受動側・防御側・現状維持側が勝利する。**

例：

- 攻撃 vs 回避 → 同値なら回避成功
- 拘束 vs 抵抗 → 同値なら拘束失敗
- 操作 vs 抵抗 → 同値なら操作失敗
- 凝 vs 隠 → 同値なら隠を見破れない

クリティカル／ファンブルは、この同値ルールより優先する。


<a id="02-checks-sec-3"></a>

### クリティカルとファンブル

出典：Ver.0.2 第3節。

2D6の出目そのものを見る。

- **6・6＝クリティカル**
- **1・1＝ファンブル**

それぞれ発生率は約2.8%。

##### 通常判定

クリティカルは原則として自動成功。

ファンブルは原則として自動失敗。

ただし、不可能な行動をクリティカルで可能にすることはできない。不可能な行動にはそもそも判定を行わせなくてよい。

##### 対抗判定

- クリティカルは通常成功より優先
- ファンブルは通常結果に敗北
- 両者クリティカル、または両者ファンブルなら最終達成値を比較
- それでも同値なら受動側が勝利

##### 攻撃クリティカル

攻撃は自動命中。

命中差による威力補正を最低でも**+2**として扱う。

通常の命中差から+3になる場合は+3を使用する。

##### 攻撃ファンブル

攻撃は失敗する。

GMは必要に応じて軽度の状況的不利益を発生させてもよいが、必ず重大事故・武器破壊・味方への誤射などを発生させる必要はない。


<a id="02-checks-sec-5"></a>

### 技能

出典：Ver.0.2 第5節。

技能値は0～5。

| 値 | 習熟度 |
|---:|---|
| 0 | 未経験 |
| 1 | 少し経験 |
| 2 | 一般的訓練 |
| 3 | 専門家 |
| 4 | 一流 |
| 5 | 達人 |

技能と能力値の組み合わせは固定しない。

**技能＝何をするか**

**能力値＝どのように行うか**

として、その状況に適した組み合わせを使用する。

##### 暫定技能

格闘、運動、耐久、回避、射撃、隠密、手先、観察、追跡、察知、調査、医学、機械、電子、知識、集中、看破、交渉、威圧、欺瞞、心理。

初期技能ポイントは**25点**を暫定値とする。

初期技能値上限は4。

技能一覧・初期ポイント数はテストプレイで調整する。


<a id="02-checks-sec-6"></a>

### 専門分野

出典：Ver.0.2 第6節。

初期作成時に専門分野を2つ取得する。

関連する判定に**+2**。

専門分野は職業クラスではなく、その人物が何に詳しいかを表す。

例：

犯罪組織、古代遺跡、幻獣、医療、宝石、武術、毒物、IT、裏社会、航海、サバイバルなど。

## 第3章 キャラクター作成

[シート](../play/character-sheet.md)を複製し、次の順番で記入する。完成例は[サンプルPC](../play/sample-characters.md)。

<a id="03-character-creation-a04"></a>

1. 名前、目的、仲間と協力する理由、得意なことを決める。全員、念を習得済み。ハンター資格の有無は設定で決める。
2. 下記の方法で能力値を合計21点、各1～6にする。
3. [技能](02-checks.md)に25点を配分する。**暫定補足 A04：初期取得**として1点につき技能値+1、未取得0、各上限4とする。成長時の必要点とは別である。
4. 専門分野を2つ、広すぎない分野名で取得する。「あらゆる念」「戦闘全般」ではなく「港湾物流」「毒物」のように具体化する。
5. 念技術3、[念系統](04-nen.md)を決める。1D6なら強化・変化・放出・具現化・操作・特質を順に1～6へ対応させる（暫定補足 A04）。
6. 最大オーラ=10+精神×3、現在オーラ=最大、拘束オーラ0、発容量=8+念技術=11、負傷点0、成長点0を記入する。
7. [発の作成](05-hatsu.md)に従い発を作り、全発の構築値合計を容量以内にする。GMと性能・消費・行動・抵抗・解除を合意する。**暫定補足 A04**として初期の発取得に成長点は使わない。
8. [装備](08-equipment-and-recovery.md)から持ち物を相談して決め、攻撃と回避の式を書く。**暫定補足 A04**として初期は標準武器1つまたは拳銃1丁、軽防具、職業上の道具、通信端末を基本とし、買い物や通貨の細かな管理は行わない。医療担当は医療キットを持てる。
9. 戦闘開始時の配分案（例2/2/1）を書き、仲間と役割を相談する。

### 完成チェック

能力値合計21、技能合計25・各4以下、専門2つ、念技術3、オーラ式、発容量11以内を確認する。発の「能力原理」「できないこと」「自然な応用」「隠す情報」も言葉で説明できれば完成。

<a id="03-character-creation-sec-4"></a>

### 能力値

出典：Ver.0.2 第4節。

能力値は6種類。

- 身体
- 俊敏
- 感覚
- 知性
- 精神
- 社交

値は1～6。

能力値合計は**21**。

##### 能力値の目安

| 値 | 目安 |
|---:|---|
| 1 | 非常に不得手 |
| 2 | やや不得手 |
| 3 | 平均的 |
| 4 | 得意 |
| 5 | 非常に優秀 |
| 6 | 卓越 |

##### ポイント作成

6能力へ合計21点を割り振る。

各能力値は1～6。

##### ランダム作成：基本方式

5D6を振る。

6つ目の値を、

**21－最初の5個の合計**

とする。

6つ目が1～6に収まらなかった場合は、5D6すべてを振り直す。

得られた6つの数字は、好きな能力値へ自由に割り振る。

##### ランダム作成：選択ルール

全能力を1から開始する。

残り15点について15D6を振り、

- 1＝身体
- 2＝俊敏
- 3＝感覚
- 4＝知性
- 5＝精神
- 6＝社交

として対応する能力を+1する。

すでに6になっている能力が出た場合、そのダイスだけ振り直す。

## 第4章 念

最大オーラ・現在オーラ・拘束オーラは資源の点数。攻撃・防御・その他の「段階」は出力の配分であり、資源とは別に管理する。[戦闘](07-combat.md)と合わせて読む。

### Ver.0.3の運用

<a id="04-nen-a05"></a>

**暫定補足 A05：資源の上限。** 常に現在オーラ+拘束オーラ≦最大オーラ、各値0以上を保つ。回復できる現在オーラの上限は最大−拘束。消費は現在だけを減らし、拘束は現在から拘束へ移す。解除・持続満了では拘束から現在へ戻す。拘束分を直接消費できない。現在0では新たな発・練・堅・硬を開始できない。最後の点を支払って成立した練・堅は、その有効期間まで維持でき、次の維持時点で不足していれば終了する。成立済みの持続発は現在0だけでは解除しない。

<a id="04-nen-a06"></a>

**暫定補足 A06：その他の使用枠。** 隠・周はそれぞれその他1段階を占有し、複数物体への周は物体ごとに1段階。占有分は同時には共有できない。必要段階を割り当てられなくなった場合、使用者が維持する技術を選び、実際の配分変更と同時に維持不能な技術を終了する。発は自動ではその他枠を使わず、必要な発だけ設計時に指定する。その他段階だけで未定義の数値ボーナスは得ない。

<a id="04-nen-a07"></a>

**暫定補足 A07：念技術のタイミング。** 絶・隠・周・堅・練はそれぞれ補助行動で開始する。1回の補助行動で複数の技術は開始できない。絶・隠・周・練の任意解除は自分の手番中に行動不要で行える。解除しても使用済みの行動と消費は戻らない。絶中は念配分と念由来の攻防補正を使えず、発・他の能動的念技術を使えない。絶開始時には既存の能動的念技術と持続発を解除する。絶による技術終了・拘束返還・絶への移行は一連の切替とし、途中で返還分を他の技術へ使えない。自分の手番に絶を行動不要で解除すると直ちに纏へ戻り、未使用の行動は使える。円は探索中の主行動（通常は1回の調査行動）として感覚+念技術で索敵し、距離と難易度は実行前にGMと合意する。射程を広げるだけで自動成功や壁越しの精密情報は得ない。

<a id="04-nen-a08"></a>

**暫定補足 A08：流・練・堅・硬の併用。** 流は自分の手番に1回、行動不要で行える。敵行動への流は攻撃宣言後、判定前にリアクションで行う。堅の7段階を扱う場合も、一度の流で移動できる量は表にある5段階までとし、6段階以上の移動は別の使用機会に分ける。堅開始時と維持終了時は、総量を満たすようその場で配分を決め直す（変更不能中を除く）。堅の任意終了は自分の手番開始時、維持消費の前に行う。練は補助行動で開始し、重複せず次の自分の手番開始で切れる。追加2段階は選んだ区分に留まり、流で移せない。堅と練は併用可。ただし練の追加分を除いた堅の7段階内で防御4以上を満たす。硬では必要なその他の占有を残し、残りの使用可能な段階をすべて集中する。4段階以上の集中が必要。堅は終了し、その追加段階は使えない。練の追加段階は硬への集中に使える。硬には流の判定は不要。次の自分の手番開始まで配分を固定し、その時点で占有条件を満たすよう配分を戻す。練が先に終了した場合は追加2段階だけが消え、残りの配分固定は続く。拘束オーラがあること自体は硬の禁止条件にならない。堅を再開するなら開始費と補助行動が必要。

<a id="04-nen-a09"></a>

**暫定補足 A09：凝と隠の情報。** 隠を開始・維持する者に対し、観察可能な相手はラウンドごとに1回、隠の配分情報が必要になった時点で行動不要の凝対抗を行える。凝成功は観察者ごとに記録する。非公開の配分は紙やGMへの個別連絡で先に確定する。通常の凝で発の全性能や誓約までは判明しない。

<a id="04-nen-a10"></a>

**暫定補足 A10：未記載の系統適性。** 以下の系統表で具現化→操作、操作→具現化の補正は原文に記載がないため、両方向+2を使う。原作図から特質を経由して2つ離れる位置を埋めた提案であり、既存の記載値は変更しない。

### オーラ量

### 念系統

出典：Ver.0.2 第10節。

念系統は、

- 強化系
- 変化系
- 放出系
- 具現化系
- 操作系
- 特質系

の6種類。

1D6によるランダム決定も可能。

#### 系統適性

通常5系統は原作の六性図を基準とする。

- 自系統：+0
- 隣接系統：+1
- 2つ離れた系統：+2
- 最も不得意な系統：+3

##### 対応

**強化系**
- 強化 +0
- 変化・放出 +1
- 具現化・操作 +2

**変化系**
- 変化 +0
- 強化・具現化 +1
- 放出 +2
- 操作 +3

**放出系**
- 放出 +0
- 強化・操作 +1
- 変化 +2
- 具現化 +3

**具現化系**
- 具現化 +0
- 変化 +1
- 強化 +2
- 放出 +3

**操作系**
- 操作 +0
- 放出 +1
- 強化 +2
- 変化 +3

##### 特質系

特質系は特殊な系統として扱う。

特質系PCは、

- 特質 +0
- 強化 +1
- 変化 +1
- 放出 +1
- 具現化 +1
- 操作 +1

とする。

つまり、他の5系統すべてを準得意として扱える。

非特質系PCは、原則として特質系能力を取得できない。

##### 複数系統を使う発

発で使用している**念系統ごとに1回ずつ**系統補正を加える。

同じ系統を一つの発の中で複数用途に使っても、補正は重複しない。

不得意系統を使用しても、発の強度そのものを下げることはしない。

代わりに、構築値が増加して発容量を圧迫する。


<a id="04-nen-sec-11"></a>

### 基礎念技術

出典：Ver.0.2 第11節。

#### 纏

通常の念状態。

原則として常時維持されているものとする。

#### 絶

オーラを閉じ、気配を消す。

探索・隠密などに有効。

絶の間は念による防御をほぼ失う。

#### 練

瞬間的に通常以上のオーラを出力する。

**現在オーラ2点を消費。**

次の自分の手番開始まで、

**攻撃・防御・その他のいずれか一つへ、追加で+2段階のオーラを配分する。**

通常5段階の配分を一時的に超えることができる。

#### 凝

能動的に周囲の念・異常を注意深く観察する場合は主行動。

相手が隠を使用した場合のみ、行動消費なしで直接対抗できる。

凝：

**2D6＋感覚＋念技術**

隠：

**2D6＋精神＋念技術**

凝側が勝利した場合、そのラウンド中は隠を見破る。

そのラウンド中に後から行われた流によるオーラ移動も確認できる。

次ラウンドになると、再び隠の効果が有効になる。

#### 隠

補助行動で開始。

維持中は、その他オーラ1段階を固定して使用する。

通常公開情報であるオーラ配分と流による移動を隠す。

発による隠蔽強化については、発の「隠蔽」カテゴリで処理する。

#### 円

探索・索敵用。戦闘中も主行動で単発の索敵ができる。使用前に目的・距離・難易度を確認し、2D6＋感覚＋念技術で判定する。成功情報の範囲はGMが条件から示す。継続的な自動索敵、隠の自動無効化、詳細な能力の把握や戦闘補正は自動で得られない。

#### 流

戦闘中のオーラ配分変更。

1段階分のオーラ移動は自動成功。

2段階以上を一度に動かす場合、

**2D6＋俊敏＋念技術**

を使用。

目標値：

| 移動量 | 目標値 |
|---:|---:|
| 2段階 | 10 |
| 3段階 | 12 |
| 4段階 | 14 |
| 5段階 | 16 |

「移動量」は、実際に移動したオーラ点数で数える。

例：

2/2/1 → 4/1/0 は2点を移動しているため、2段階変更。

通常失敗の場合でも、宣言した変更のうち合法な1段階だけは変更できる。リアクションは失敗・ファンブルでも消費する。

ファンブルの場合は変更できない。

敵の行動に対応して流を使用する場合はリアクションを消費する。

#### 周

補助行動で開始。

物体をオーラで覆い、念戦闘に耐えられる状態にする。

基本的に**その他オーラ1段階**を使用する。

周を施した武器は攻撃威力+1、周を施した防御物は防護値+1を暫定値とする。

同じ攻撃・被攻撃に複数の周が適用できても、同種の周補正は最大+1。防御物はその攻撃を実際に防げる位置・範囲で使う。周の威力+1は、同じ攻撃の硬の威力補正と重複して加算しない。

硬で武器へ集中する場合、周はその武器を硬の焦点として使用可能にする役割を持つ。

通常の物体を周なしで極端な念攻撃に使用した場合、GM判断で破損することがある。

細かな耐久値管理は行わない。

#### 堅

全身を高出力の念で守り続ける。

補助行動で開始し、開始時に**現在オーラ2点を消費**。開始手番に維持費は重ねず、初回の維持判断は次の自分の手番開始に行う。

以降、維持する場合は自分の手番開始時に**現在オーラ1点を消費**。

堅の間は、通常5段階のオーラ配分が**合計7段階**になる。

ただし、

**防御オーラを最低4段階**

維持しなければならない。

#### 硬

主行動による攻撃等に付随して使用。

必要なその他枠を残し、堅の追加段階を除いた残り全部を攻撃へ集中する。集中4段階で最終威力+1、5～7段階で+2。4段階未満では使用できない。練による追加段階も集中に使える。

硬使用時に堅は終了する。防御0となり、次の自分の手番開始まで流を含め配分を変更できない。練の満了による追加段階の消失は配分変更に数えない。

通常近接では集中段階を攻撃オーラとして計上し、硬の補正を1回加える。発では元の発威力に硬の補正だけを加え、攻撃オーラを重ねない。同じ打撃の通常近接と発は高い基礎威力1つを使い、硬の補正も1回だけ適用する。周付き武器を硬の焦点として維持できるが、周の威力+1は重ねない。

## 第5章 発の作成

念能力はリストから選ぶ魔法ではなく、能力原理から設計する。まず「何を実現するか」「どんな仕組みか」を1～2文で書き、[発シート](../play/hatsu-sheet.md)を埋める。

### 設計から使用まで

1. 主効果と強度を選び、必要な系統を列挙する。原理から自然な応用と、独立した追加効果を分ける。
2. 最大射程・範囲・持続・特殊性を決める。複合効果があれば追加分と共通項を分けて計算する。
3. 系統適性は使用系統ごとに1回加え、全発の構築値合計を発容量以内にする。
4. 強度5～6の根拠になる条件、代償、誓約と違反結果をGMと決める。構築値は割り引かない。
5. 行動、判定、抵抗、成立効果、消費または拘束、持続終了、再使用・解除条件を記入する。
6. 最大性能での構築値と、今回使う性能での消費を区別する。

### Ver.0.3の使用手順

<a id="05-hatsu-a11"></a>

**暫定補足 A11：発の行動と失敗。** 特記しない発は主行動。仮宣言で性能・必要オーラを確認し、宣言確定後に対象が対応する。費用の内訳は[単発と持続](05-hatsu.md#sec-24)を使う。単発消費と発動消費は失敗しても返さず、持続分は設計時に決めた成立条件を満たしてから拘束する。成立しなかった持続分を既に拘束していれば返す。主行動は戻らない。抵抗不要の自分用効果は原則判定不要。持続の数ラウンドは設計時に2～5のどれかを決め、成立ラウンドを1回目とし、指定回数目の自分の手番終了に満了する。行動不能で飛ばした手番位置でも満了する。任意解除は自分の手番中、行動不要。他者の能力は解除できない。気絶時の維持条件は発ごとに定める。性能変更は原則補助行動で、発動消費の未払い増額分と持続確保の差額を調整する。縮小で戻るのは拘束差額だけ。同じ発の再拡大では既払発動消費を重複請求しない。

<a id="05-hatsu-a12"></a>

**暫定補足 A12：距離と規模。** 本書の初期設定は接触=手が届く、近距離=同じ部屋、中距離=隣の部屋や同じ通り、長距離=見通せる遠方、超遠距離=その外側。小範囲=部屋の一部、広範囲=部屋全体、非常に広範囲=建物以上。地形による違いは宣言前にGMが示す。指定する複数対象は最大数を、範囲効果は境界と味方を巻き込むかを設計時に決める。射程内でも認識できない対象への直接指定は原則不可。効果自体が探知・自動反応を備える場合はその設計に従う。

<a id="05-hatsu-a13"></a>

**暫定補足 A13：複合発の消費。** 選択式は今回選んだ効果、同時発生式は今回発生する効果の強度合計を使う。共通の射程・範囲は各1回、治療を含むなら追加消費+1も加える。自動識別型は設計時に識別条件・対象選別・不明な対象の扱いを定め、GMが仮宣言の実対象と必要額を確認する。オーラ不足の場合の再宣言は、秘匿管理の有無を問わず同じ手番に1回まで。再度不可なら新しい発の宣言をやめ、未使用の主行動を別行動に使える。一般の宣言手順は[戦闘](07-combat.md#a16)を参照する。対象側の対応後は確定済みの対象・性能を変更せず、費用も再計算しない。

<a id="05-hatsu-a14"></a>

**暫定補足 A14：カテゴリ別の標準性能。** 発の性能は以下の標準を起点に設計時にGMと合意する。強度5～6、標準に収まらない特殊な発は個別評価。適用対象・判定・行動・重複・突破・解除と維持条件を発シートに記入する。

| カテゴリ | 強度1 | 強度2 | 強度3 | 強度4 |
|---|---|---|---|---|
| 防護強化 | 防護+1 | +2 | +2 | +3 |
| 強化 | 限定行動+1 | 特定技能・用途+1 | 一分野の関連判定+1 | 一分野の関連判定+2 |
| 隠蔽 | 関連対抗+1 | +2 | +2 | +3 |
| 生成 | 単純な小物 | 一般的な道具・武器 | 高性能な道具・戦闘用具 | 大型・複雑な道具 |
| 妨害 | 極めて限定的な判定−1 | 特定判定−1 | 複数の関連判定−1 | 特定判定−2または広い関連判定−1 |

同種の補正は最大値のみ。強化は判定補正として扱い、能力値・最大オーラ・発容量・行動回数を自動変更しない。隠蔽する情報を指定し、凝と隠の既存対抗を保つ。生成物が通常装備と同等なら既存装備値を使い、生成強度・念技術を武器威力へ加算しない。追加の攻撃・防御・操作性能は独立効果として構築する。妨害は適用・抵抗方法を定め、拘束・操作の成立対抗を省略しない。探知・移動・特殊は各カテゴリの定性的基準を用いる。

防護強化は防御オーラ・防具・堅・適用可能な周付き防御物と加算できる。適用する現象を定め、持続条件内の各攻撃で使う。通常の負傷値計算で突破し、標準では累積耐久値を設けない。瞬間防御は同じ補正を用い、攻撃宣言後・攻撃判定前のリアクションで開始し、その攻撃1回だけに適用する。単発消費を払い、通常回避と組み合わせられる。同じ攻撃へ流を重ねる扱いは[時間処理](07-combat.md#a16)に従う。

障壁型は独立した遮断として扱う。障壁突破値＝防御強度＋術者の念技術、突破用攻撃値＝攻撃威力＋命中差補正。後者が上回れば通過し、同値以下は遮断する。通過した攻撃に障壁値を再減算しない。標準の累積耐久値はなく、通過だけでは障壁を失わない。障壁を破壊する目的の攻撃が突破すれば破壊できるが、その攻撃は背後へ同時命中しない。同一経路の同種障壁は最大値のみ、別地点は通過順に比較する。位置・向き・大きさ・防御範囲・迂回条件を設計時に指定する。

同じ能力原理から直接導く応用は追加構築値不要だが、必要な判定は行う。新しい独立性能・対象数・特殊性・自動効果・貫通等は構築に戻す。攻撃・拘束・操作・治療は既存の標準処理を使う。


### 構築と拘束の計算例

変化系が「粘着糸」を作る。拘束強度3+近距離1+単体0+3ラウンド1+特殊性0+変化適性0=構築値5。相手を捕らえるときは基本値4に対する発動消費2を払い、成立後に持続分2を拘束する。糸を手すりに結び付けて体を支える用途は同じ原理の自然な応用。転移や記憶読取は糸の説明だけでは増やせない。

最大オーラ22、現在22から発動消費2と拘束2で現在18・拘束2。さらに練で2消費すれば現在16・拘束2。糸を解除すると現在18・拘束0。休息しても現在+拘束が22を超えることはない。

<a id="05-hatsu-sec-12"></a>

### 発容量

出典：Ver.0.2 第12節。

**発容量＝8＋念技術＋容量拡張**

念技術3なら基本発容量11。

発容量は、**所有するすべての発の構築値合計の上限**である。

例：

発A：構築値5  
発B：構築値4  

なら合計9。

発容量11なら取得可能。

軽い発を複数持つことも、一つの複雑・特殊な発へ容量の大半を使うこともできる。


<a id="05-hatsu-sec-13"></a>

### 発の作成

出典：Ver.0.2 第13節。

最初に能力コンセプトを決める。

その後、

- 使用系統
- 基本効果
- 強度
- 射程
- 対象・範囲
- 持続
- 特殊性
- 制約
- 代償
- 誓約

を設定する。

**柔軟性そのものには構築値を要求しない。**

同じ能力原理から自然に導ける応用は、追加構築値なしで自由に試みてよい。

例：

「粘着性の糸」を作る発なら、

- 拘束
- 物を引く
- 糸を壁へ付けて移動
- 糸を張って振動を察知
- 足場として利用

などは、能力原理から自然なら追加構築値を要求しない。

能力原理から説明できない新しい効果には、追加構築値が必要。

<a id="05-hatsu-sec-15"></a>

### 発の強度

出典：Ver.0.2 第15節。

強度1～6。

| 強度 | 基準 |
|---:|---|
| 1 | 小さな効果 |
| 2 | 実用的 |
| 3 | 一般的な念能力者の主力 |
| 4 | 強力 |
| 5 | 非常に強力 |
| 6 | 通常限界を超えた効果 |

通常、制約なしで取得できるのは強度4まで。

強度5以上には相応の制約・代償・誓約などが必要。

#### 攻撃

1：牽制程度  
2：実戦的  
3：一般的な主力攻撃  
4：強力な攻撃  
5：決め技級  
6：厳しい条件下で極めて高い致死性

#### 防御

1：軽い攻撃の軽減  
2：通常攻撃への実用的防御  
3：一般的な念攻撃への主力防御  
4：強力な発へ耐える  
5：条件下で非常に高い防御  
6：厳しい条件下でほぼ突破不能

#### 強化

1：小さな補助  
2：明確な強化  
3：能力値1段階程度の明確な向上  
4：能力値2段階程度の強力な向上  
5：一分野で常識外れ  
6：条件下で圧倒的

※具体的な能力値加算方法は発ごとにGMと調整する。

#### 拘束

1：軽い妨害  
2：一部行動を制限  
3：移動不能など明確な拘束  
4：多くの身体行動を大幅制限  
5：条件下でほぼ完全拘束  
6：厳しい条件下で絶対拘束級

#### 操作

1：一瞬の誘導  
2：単純な行動を1回強制  
3：数ラウンドの単純命令  
4：複雑な行動を強制  
5：条件下で意思決定をほぼ支配  
6：厳しい条件下で完全操作

対象自身の生命・信念・重大な利益に反する命令には、より高い強度を必要とする。

#### 探知

1：存在の有無  
2：大まかな位置・数  
3：位置・移動の継続把握  
4：詳細な状態や特徴  
5：通常隠しにくい情報まで高精度取得  
6：厳しい条件下で極めて精密な情報取得

記憶・未来などは特殊性も必要。

#### 隠蔽

1：少し発見しにくい  
2：通常の凝に対して明確な優位  
3：専門的に探されても見破りにくい  
4：熟練者でも発見困難  
5：条件下で極めて発見困難  
6：厳しい条件下で通常手段ではほぼ発見不能

#### 移動

1：軽い移動補助  
2：高速移動・高跳躍  
3：通常困難な立体移動  
4：大幅な高速移動・特殊移動  
5：条件付き瞬間移動級  
6：厳しい条件下で大規模な空間移動

瞬間移動などは別途特殊性を要求する場合がある。

#### 生成

1：単純な小物  
2：実用品・通常武器  
3：高性能な道具・戦闘用具  
4：大型・複雑・非常に高性能  
5：条件下で極めて特殊  
6：通常では成立しない規模・性能

生成物そのものとは別の特殊能力を持つ場合、その能力分の構築が必要。

#### 妨害

1：軽い不利  
2：特定判定に-1程度  
3：複数の関連行動に明確な不利  
4：戦闘能力を大きく低下  
5：条件下で能力を著しく制限  
6：厳しい条件下で特定能力をほぼ封殺

発そのものを封印するなどの場合は特殊性も必要。

#### 特殊

特殊効果そのものの強力さ・自由度・確実性を表す。

特殊性とは別に判定する。

<a id="05-hatsu-sec-20"></a>

### 特殊性

出典：Ver.0.2 第20節。

特殊性は「珍しさ」ではなく、**通常ルールをどれだけ飛び越えるか**で判断する。

| 特殊性 | 基準 |
|---:|---|
| +0 | 通常カテゴリで処理可能 |
| +1 | 通常効果へ小さな特殊ルールを追加 |
| +2 | 本来取得できない情報・状態へ干渉 |
| +3 | 念能力・空間などシステム根幹へ干渉 |
| +4 | 時間・因果など通常ルールを大きく覆す |

例：

+0：
攻撃、通常拘束、身体強化、通常探知、通常治療など。

+1：
マーキング、特定条件のみを識別する探知など。

+2：
記憶読取、強制絶、限定的瞬間移動など。

+3：
発の封印、能力コピー、異空間生成、限定的未来予知など。

+4：
非常に強力な予知、広範囲な能力コピー、因果干渉など。

特殊性が高いだけで自動的に許可されるわけではなく、内容によって制約等を要求する。


<a id="05-hatsu-sec-21"></a>

### 複合発

出典：Ver.0.2 第21節。

複数の効果を持つ発は、以下の3種類に分ける。

##### 自然な応用

同一の能力原理から自然に生じる用途。

**追加構築値なし。**

##### 選択式副効果

一度の使用では、主効果か副効果のどちらかしか発生しない。

追加構築値：

**副効果強度÷2、端数切り上げ**

##### 同時発生副効果

一度の成功で、主効果と副効果が同時に発生する。

追加構築値：

**副効果強度をそのまま加算**

射程・範囲・持続が共通なら二重計上しない。

副効果だけ異なる性能を持つ場合は差額を追加する。

特殊性・系統適性は必要に応じて別途加算する。


<a id="05-hatsu-sec-22"></a>

### 制約・代償・誓約

出典：Ver.0.2 第22節。

これらは**構築値を安くするための点数ではない。**

通常では成立しない性能を成立させる根拠として扱う。

##### 発動条件

能力使用に必要な手順・条件。

##### 制約

使用機会・対象・状況を狭める。

##### 代償

使用時または使用後に必ず受ける不利益。

##### 誓約

自ら定めたルール。

破ること自体は可能だが、破った場合に重大な結果を受ける。

#### 重さの目安

##### 1：軽い

ほぼ困らない。

例：
能力名を叫ぶ、決まったポーズを取る。

強度5以上の根拠には基本的にならない。

##### 2：明確な不便

実戦で時々困る。

例：
両手が必要、主行動1回の準備が必要。

##### 3：大きな制限

戦術へ明確な影響。

例：
特定条件の対象のみ、戦闘中1回、1ラウンド準備など。

強度5を成立させる有力な根拠。

##### 4：非常に重い

戦い方自体を縛る。

例：
特定人物にしか使えない、使用後重傷、誓約違反で発を永久喪失。

##### 5：極端

生命・念能力・人生そのものを危険にさらす。

例：
誓約違反で死亡、一生に一度、使用後念能力を永久喪失。

強度6など通常限界を超える能力の根拠。

軽い条件を大量に重ねても、高い制約とは評価しない。

実際のゲーム上の不便・危険を評価する。

##### 強度との関係

強度1～4：
原則として制約なしでも取得可能。

強度5：
原則、重さ3以上相当の条件が必要。

強度6：
原則、重さ4～5相当の非常に重い条件が必要。

ただし機械的な交換レートではなく、能力内容との釣り合いをGMが判断する。


<a id="05-hatsu-sec-23"></a>

### 発のオーラ消費

出典：Ver.0.2 第23節。

基本値：

**強度＋実際に使用した射程＋実際に使用した範囲**

最大性能ではなく、その使用で実際に使った性能を計算する。


<a id="05-hatsu-sec-24"></a>

### 1ラウンド型と持続型

出典：Ver.0.2 第24節。

##### 1ラウンド以内

基本値を**現在オーラから消費**する。

##### 2ラウンド以上の持続

基本値をBとして、発動時に **ceil(B/2)** を消費し、成立時に **max(1, floor(B/2)+T)** を拘束する。ceilは端数切上げ、floorは切捨て。Tは2～5ラウンドで0、1シーンで1、数時間で2、1日以上で3以上とする。

仮宣言で発動・確保・初回反復の必要額を確認し、不足する性能では開始できない。確定後の対象の回避・抵抗・移動を見て消費を再計算しない。終了・満了では拘束分だけを現在へ戻し、発動分は返さない。複数の持続発は個別に拘束を記録し、合計する。現在0だけでは既存発は解除しない。

##### 維持と反復

成立済みの防護上昇・探知領域などの維持は原則追加行動・消費不要。新しい攻撃・治療・独立した盾の生成は反復で、今回の効果強度合計＋治療を含む場合1を消費する。維持済みの射程・範囲は重複請求しない。能動反復は原則主行動、攻撃への反応防御はリアクションを使う。同じ使用者の同じ発につき標準で1ラウンド1回。確定後の失敗も回数に数え、同ラウンドの解除・再発動や再侵入では回復しない。

発動と初回反復は同じ主行動で行えるが反復費用も必要。持続形成が不成立なら未発生の初回反復消費は請求せず、持続成立後の反復失敗では反復費用を返さない。完全自動の反復は特殊性等を評価する例外で、条件・時点・対象選別を設計時に指定する。

対象付与型は発動時の対象を固定し、後から入った者へ自動追加しない。持続領域型は領域内の維持効果を新規侵入者にも条件に従って適用する。新たな攻撃等は反復枠で処理する。離脱すれば原則領域効果は外れる。同じ領域への出入りだけで抵抗を無制限に振り直さない。


<a id="05-hatsu-sec-25"></a>

### 治療系の発

出典：Ver.0.2 第25節。

治療は通常の発より重い。

基本消費：

**治療強度＋1＋射程＋対象補正**

| 強度 | 治療可能範囲 | 接触・単体消費 |
|---:|---|---:|
| 1 | 止血・痛み軽減 | 2 |
| 2 | 軽傷 | 3 |
| 3 | 負傷 | 4 |
| 4 | 重傷 | 5 |
| 5 | 瀕死 | 6 |
| 6 | 通常困難な重大損傷 | 7以上 |

強度2以上による通常治療では、原則として**1回につき負傷点1点回復**。

強度が高いほど回復量が増えるのではなく、**治療できる負傷の重さが上がる。**

例：

重傷3点へ強度4治療を使用。

3 → 2

さらに使用すると、

2 → 1

となる。

##### 瀕死

強度5なら、

- 瀕死・危険 → 瀕死・安定
- 安定済みの瀕死者へ使用 → 負傷点4→3

が可能。

##### 致命傷

強度5で生命を安定させることは可能。

致命的な損傷そのものを完全治療するには、原則として強度6が必要。

##### 強度6

欠損、重大な臓器損傷など、通常では治療困難な損傷を扱う。

相応の制約・代償・誓約等を必要とする。

死者蘇生は通常の治療発では不可。

治療発は同じ傷へ複数回使用可能。

そのたびに通常通りオーラを消費する。

## 第6章 探索・調査・交渉

### 会話と判定の流れ

GMは見える物・聞こえる音・NPCの態度を伝える。プレイヤーは目的と手段を宣言する。確実にできることはそのまま成功し、失敗が場面を変えるときに判定する。GMは振る前に能力値+技能、目標値または対抗側、所要時間、失敗結果を示す。

棚を調べるなら感覚+観察、記録を照合するなら知性+調査、証人の恐怖を理解するなら精神または社交+心理など。技能の選択は固定しない。力で扉を開く身体+運動と、構造を読んで開く知性+機械は異なる手段になる。

<a id="06-adventure-a15"></a>

**暫定補足 A15：協力と再挑戦。** 1つの目的には代表者1人が判定する。協力者は具体的な貢献を説明し、実行可能なら代表者へ+1、複数人でも合計+1まで。技能値を合算しない。専門分野の補正は代表者自身のものだけ。戦闘中の協力は主行動を使い、次の代表者の手番終了までの関連判定1回に有効。同じ状況・手段での失敗を振り直し続けられない。新しい証拠、道具、交渉条件、代わりに受け入れる時間経過など、状況を変えて再挑戦する。攻撃・脱出・応急処置など反復を定めた行動は個別ルールに従う。

### 調査を止めない

主要な行き先を示す手掛かりは、適切な場所を調べれば渡す。判定成功では追加情報、時間短縮、安全な接近方法を得る。失敗時も別ルートを用意し、手掛かりが一切出なくなる進行を避ける。これはGMのシナリオ運用指針であり、すべての情報を自動取得する能力ではない。

### 交渉と秘密

NPCの希望、恐れ、譲れない条件をGMが決める。交渉成功は可能な条件の中で協力を得ることであり、思考や記憶を操作する効果ではない。PCの発や配分の秘密はGMへ伝えて管理できる。プレイヤーが知った秘密とPCが見抜いた情報は分ける。

能力の観察では「触れた印だけが反応した」「糸が壁へ伸びた」など実際の現象を伝える。追加調査や凝、試し行動で仮説を検証し、条件が分かれば回避策に結び付くようにする。

## 第7章 戦闘

開始前に[念技術](04-nen.md)と[装備・負傷](08-equipment-and-recovery.md)を参照。攻撃が命中しただけでは負傷点は決まらず、威力と防護を比べて負傷値を算出する。

### 手番の手順

<a id="07-combat-a16"></a>

**暫定補足 A16：戦闘の時間処理。** Ver.0.4では以下を共通手順とする。

#### 開戦と手番

開戦時に配置と通常5段階の配分を決め、2D6＋俊敏で行動順を決める。同値なら素の俊敏、高い1D6の順で比較し、再同値の組だけ振り直す。戦闘中は順番を固定する。途中参加者は参加時に振り、解決中の行動を終えてから順番へ挿入する。挿入位置が過ぎていれば次ラウンドから手番を得る。参加時の位置は直前の行動と入口からGMが示す。

開戦・参加時にリアクション1回を得る。自分の初手前にも使える。自分の手番開始時は次の順で処理する。

1. 練の追加2段階を除き、硬の配分固定を解除する。維持する技術の占有条件を満たす配分へ戻し、必要枠を失った技術を終了する。
2. 堅の維持費を支払うか終了する。
3. リアクションを1回へ更新する。残数は持ち越さない。

主行動・補助行動・通常移動は任意の順で、それぞれ解決してから次へ進む。主行動で攻撃、発、凝、脱出、応急処置、協力などを行う。補助行動を主行動の代用にはできない。通常移動を主行動の前後に分割しない。流は自分の手番に行動不要で1回。任意解除は各効果が認める時点で行い、他の行動の解決中には割り込まない。練を補助行動で開始し、その手番の主行動に硬を使える。

手番終了時に未使用の主行動・補助行動・移動を失い、該当する持続満了を処理する。全員の手番位置を通過したらラウンド末。反復効果のラウンド回数を更新する。練は次の自分の手番開始まで維持する。硬の固定中に練が切れた場合は追加2段階だけを除き、残りの配分を次の自手番まで保つ。

#### 行動の宣言と解決

1. 仮宣言で行動、対象、性能、経路を示す。
2. 対象認識・条件・行動枠・必要資源を確認する。発の初回反復を行うならその費用も含める。
3. 宣言を確定する。
4. 対象側が対応を宣言する。
5. 各効果の定義に従って消費と対応を解決する。
6. 命中・抵抗等を判定する。
7. 威力・防護・負傷・状態を適用する。
8. 終了条件を確認する。

宣言確定後は相手の対応を見て対象・性能を変更したり撤回したりできない。対応で対象が離脱しても確定した費用を再計算しない。発動前の資源不足では行動枠・オーラを消費しない。公開情報で分かる不足は仮宣言中に調整できる。GMが秘匿条件を照合して発動不可を伝えた場合、同じ手番で発の再宣言は1回まで。再度不可なら未使用の主行動を発以外に使える。自動識別型複合発は公開・秘匿を問わず再宣言1回までとする。

単発消費・発動消費は判定失敗でも戻らない。持続分は[発の使用](05-hatsu.md#a11)で定めた成立時に拘束し、持続自体が不成立なら確保済み分を返す。未発生の初回反復は請求しない。成立後の反復が外れた場合は反復消費が残る。

#### 対応と行動不能

通常回避はリアクション不要。各キャラクターが同じ攻撃に使えるリアクションは原則1回で、流と瞬間防御を重ねられない。対応は攻撃の出目前に確定し、流の配分変更を先に解決してから命中・回避を判定する。持続中の防護や障壁は適用条件内なら対応枠を使わない。硬の固定中は流で動かせず、通常回避と配分変更を伴わない適法な対応は使える。

拘束で制限される行動はその発に従う。脱出に主行動を使って成功すれば、未使用かつ実行可能な補助行動・通常移動を続けられる。手番前から行動不能なら行動枠を使えない。手番途中で行動不能になった場合、原因となった処理と成立済みの効果を適用し、続行不能な行動を打ち切る。行動不能中は能動回避・リアクションを行えない。瀕死・安定も原則行動不能。飛ばした手番を取り直さず、その手番位置で持続満了を確認する。気絶時の発は設計済みの維持条件に従う。

<a id="07-combat-a17"></a>

**暫定補足 A17：移動と接敵。** GMは開戦時に区画、通行可能な接続、初期位置、把握できる障害・遮蔽・距離帯を示す。単純な場は1区画とし、移動や射線の選択に影響する地形で区画を分ける。区画内の位置も接触や遮蔽に影響する。

通常移動1回で通行できる同一区画内の地点へ移動する。徒歩で別区画へ移るには、通常移動＋主行動を同時に使い、直接接続する1区画へ移る。経路と到達点を宣言する。平易な移動は判定不要。移動中に越えられる難所なら技能・目標値・失敗時に止まる位置と危険を宣言確定前にGMが示す。別の作業が必要な障害は先に解決する。主行動で扉を開けた手番は、通常移動だけで別区画へ渡れない。失敗・中断でも確定済みの移動枠を消費し、最後の到達地点を記録する。発の追加移動・運搬は個別条件に従う。

手が届く位置に到達したら接触攻撃ができる。離脱で自動機会攻撃は発生しない。発に定義した手番外反応はA16で解決する。移動不可の拘束から脱出した手番は、未使用の通常移動で同一区画内を動ける。

[距離帯](05-hatsu.md#a12)は射程と消費を決め、区画の徒歩接続と別に示す。射程内でも対象認識と経路を確認する。半遮蔽は射撃への回避＋2程度、ほぼ完全な遮蔽は直接射撃不可。認識・遮蔽を越える性能、範囲の起点・対象選別は発の設計に従う。途中参加だけで追加移動や接敵は得られず、参加時の対応枠は以後の行動に使う。

<a id="07-combat-a18"></a>

**暫定補足 A18：発攻撃と抵抗。** 発シートに命中式・対象・行動・抵抗・適用条件を記す。

#### 命中・防護・障壁

回避可能な対象とは通常の命中対抗を行い、射撃型の発には経路に応じた遮蔽を適用する。対応で射程・範囲外へ出たり経路が塞がった対象には効果を適用しない。通常同値は回避側勝利。[特殊出目](02-checks.md#a03)を優先する。

無人の固定物や行動不能の対象には能動回避を振らせない。届くことが明らかなら命中を省略し、命中差補正＋0。精度が不確実ならGMが既存の難易度を事前提示して命中判定を行い、この場合も標準の命中差補正は＋0。振った攻撃がクリティカルなら威力補正は最低＋2。防護・障壁・成立抵抗の適用条件は個別に確認する。 固定物の半遮蔽は精密判定の目標値に＋2を適用する。回避対抗の遮蔽補正と同じ遮蔽を重ねない。ほぼ完全な遮蔽で射線が通らなければ直接射撃はできない。

物体の位置・材質・大きさと破壊に必要な威力・条件を宣言確定前にGMが示す。固定物へ術者の身体・防御オーラを自動適用しない。能動的に保持して守れる携行物は保持者の回避との対抗を使い、宣言した物体だけを対象とする。物体への命中を人物の負傷へ転用しない。破壊により維持条件を失った発は終了し、その拘束オーラだけを返す。

発攻撃の負傷値は発威力＋命中差補正−通常防護値。攻撃オーラや通常武器の補正を発威力へ加えない。同じ打撃で通常近接と攻撃発を併用する場合は、使用条件を満たす高い基礎威力1つを使い、命中差と硬の補正を各1回適用する。通常側を選んでも確定した発の費用は残る。

[防御発](05-hatsu.md#a14)の防護強化・瞬間防御を適用する。同種補正は最大値。障壁は命中確認後に経路ごとに比較し、攻撃威力＋命中差補正が防御強度＋術者の念技術を上回れば通過、同値以下は遮断。通過時は障壁値を減算せず通常防護を1回適用する。同経路の同種障壁は最大値、別地点は通過順に比較する。障壁を破壊する攻撃で背後へ同時命中はしない。威力のない拘束・操作にも遮断は働き、突破威力や別経路を備えるかは設計時に定める。

#### 成立・脱出・操作

拘束・操作は命中と到達の後に各節の成立対抗を行う。自動命中・回避不能でも成立対抗は省略しない。防御オーラ・防具・命中差は成立式へ加えない。攻撃と拘束が付随する場合、負傷値0以下でも到達していれば設計上の条件に従って成立対抗を行う。同じ攻撃で新たにつく負傷補正を、その攻撃自身の成立対抗に遡って適用しない。

脱出は主行動で双方が新たに振る。通常同値は拘束側勝利で状態維持。成功時の返還はその発の終了条件に従う。

操作は成立時に有効となり、命令は対象が次に該当枠を使える自分の手番で実行する。進行中の処理を遡らず、残る該当枠だけを使う。追加の行動枠を得ず、実行不能な命令には枠を消費しない。命令変更、重大な利益に反する命令、再抵抗機会、終了、他操作の上書き性能は設計時に合意する。標準では毎手番の無料再抵抗を与えない。相容れない命令は先に成立したものを優先し、後の命令は競合中の枠を使えない。後の操作が残っていれば競合解消後の該当枠で実行できる。

#### 複数対象

同一の範囲・複数対象攻撃は、攻撃側の命中用2D6を1回振り、対象ごとに経路・遮蔽・回避を計算する。同じ強度・同じ効果の成立判定も術者側の出目を共有し、対象は個別に抵抗する。独立した攻撃や別種の効果は設計に従って別判定。特殊出目は共有する。

対応は出目前に確定し、同一効果の判定には解決時点の状態を用いる。その攻撃が生む負傷・拘束で未処理の対象の判定を遡って変えない。回避・抵抗の成功人数で共通費用を再計算しない。対象付与型で「少なくとも1人に成立」が持続条件なら、全員不成立では確保せず、一部成立では成立対象だけに残る。先に持続領域が成立した場合は、全員が抵抗しただけでは領域を終了しない。

### 1ラウンドの例

[サンプルPC](../play/sample-characters.md)のアキラは身体5、格闘4、標準武器+1。初期配分2/2/1から、手番の流で3/1/1へ1段階動かす（自動成功）。出目7で命中16。敵の回避は出目6+俊敏3+回避2=11。命中差5で威力補正+2。

打撃値=身体5+攻撃3+武器1=9。敵の防護=身体3+防御2+軽防具1=6。負傷値=9+2−6=5で重傷、負傷点3。敵は身体・俊敏全般−1、負傷部位に直接関係するなら−2（合計−3にはしない）。敵が降参すれば戦闘終了。戦うなら同じラウンドの自分の手番に行動できる。

<a id="07-combat-controlled-attack"></a>

#### 選択ルール・手加減

この選択ルールを使うかは開始前に卓で決める。攻撃者は、通常攻撃または負傷を与える発の宣言確定前に手加減を宣言できる。通常の命中・防護・特殊出目を処理した後、その攻撃による最終負傷値の上限を6とする。クリティカルでも上限は6。攻撃結果を見てから変更できず、行動・オーラの消費は通常どおり。

負傷点の累積、4点到達時の生存判定、瀕死への追加有効打は通常どおり処理する。救命が必要になる可能性は残る。手加減は負傷値だけに適用し、拘束・操作や環境そのものによる危険の条件は変えない。範囲攻撃の手加減はその宣言で与える負傷全体へ適用する。継続する発の反復攻撃は各回の宣言で選ぶ。

#### 流・硬の例

2/2/1→4/1/0は移動量2、俊敏+念技術の目標値10。通常失敗なら宣言した移動のうち1段階を選び3/1/1または3/2/0へ。ファンブルなら2/2/1のまま。

硬は堅を終了し、維持する周の1段階を残して4/0/1へ集中する。アキラの周付き標準武器では打撃値は5+4+1+硬1=11。周の威力＋1は重ねない。練を併用すれば6/0/1、打撃値は5+6+1+硬2=14。5段階以上を集中できる素手の硬で、発強度3・念技術3なら発威力は3+3+硬2=8であり、さらに攻撃5を足さない。硬後は次の自分の手番まで防御0、流のリアクションも不可。その他枠を使う周の+1と硬の+2は重複しない。

## 第8章 装備・負傷・回復

この章の装備数値、自動射撃、負傷値表、回復量は原文から続くテスト対象。武器を持つことだけで念能力者への命中や突破が保証されるわけではない。

### 暫定補足による負傷と回復

<a id="08-equipment-and-recovery-a19"></a>

**暫定補足 A19：負傷点と部位。** 命中・防護後の負傷値0以下は有効打なし。1～8では軽傷1・負傷2・重傷3・瀕死4を累積し、上限4とする。有効打の描写から部位をGMと記録する。部位別の負傷点や部位狙いの追加補正は設けない。

3点以下から4点へ到達した瞬間に2D6＋身体、目標値10で生存判定1回。成功は瀕死・安定、失敗は瀕死・危険。到達前の負傷補正を生存判定に持ち込まない。4点への追加有効打は危険へ移行し、再判定しない。治療で3点以下へ戻った後の再到達は新たな瀕死として判定する。負傷値9以上は元の点数を問わず4・危険・致命的損傷ありとし、生存判定を省略する。明らかに生存不能な状況はGMが先に結果を説明する。

補正は現在の累積段階と、まだ治っていない傷が動作に直接関係するかで決める。負傷分は最も強い1つだけを適用する。複数部位や重傷の一般−1と部位直結−2を合算しない。他原因の拘束・装備補正は条件を満たせば適用する。治療で段階が下がれば直ちに新段階を使い、治った傷は治療内容に従って記録する。負傷補正は判定に適用し、威力・防護・能力値・派生値・決定済み行動順・行動回数を自動で変えない。

<a id="08-equipment-and-recovery-a20"></a>

**暫定補足 A20：治療と休息の境界。** 負傷点1/2/3/4は軽傷/負傷/重傷/瀕死に対応。医学で十分な治療をするには安全な場所で1時間程度とし、目標値10、1人につき長休息ごとに1回まで、成功で1点回復。ただし危険状態や致命的損傷は先に対応する。自然治癒の目安を満たしたら負傷点を1段階減らし、まだ残る傷は新しい段階の期間を改めて待つ。休息でのオーラ回復は最大−拘束まで。小休息の使用済みは記録し、同じ消耗では繰り返さない。長休息でリセットする。連続小休息のためだけの無意味な発使用は新しい消耗と扱わない。

<a id="08-equipment-and-recovery-a21"></a>

**暫定補足 A21：治療発の結果。** 強度1は負傷点を減らさず止血・痛み軽減。強度2以上は対象の現在段階を治療できる場合だけ1点回復する。危険の安定化は回復と別の1回。致命的損傷は強度5で安定化できるが、通常治療で負傷点だけを下げて治した扱いにせず、強度6の治療や適切な医療へつなぐ。強度6も通常1回1点とし、欠損等の回復内容は発の設計時にGMと合意する。消費した治療オーラは持続を解除しても返らない。

<a id="08-equipment-and-recovery-a22"></a>

**暫定補足 A22：弾薬と射程。** 初回は通常弾薬を細かく数えず、自動射撃のたびに「弾薬消耗」を1つ記録。3つでその武器は弾切れ、携行予備弾があれば補助行動で再装填して0に戻す。導入では予備弾1回分。拳銃・SMG・弓・ショットガンは近距離、ライフル・クロスボウは中距離、高威力ライフルは長距離を基準有効射程とする。ショットガンは中距離にも威力5で届き、この区分までは射程超過−2を適用しない。自動射撃の威力補正は通常の命中差補正から1段階（+1）増やし、上限+3。攻撃クリティカルの最低+2を適用してから増やす。これは原文の候補を試遊できるようにした暫定運用。

### 治療と資源の例

負傷点3（重傷）へ強度3治療は使えない。強度4なら接触単体の消費5で3→2。次は強度3・消費4で2→1、さらに強度2・消費3で1→0。常に強度4で治療してもよいが毎回5を消費する。

瀕死・危険（4）へ強度5を1回（消費6）で安定化、もう1回（消費6）で4→3。致命的損傷ありなら後者だけで完全治療にはならない。医学の安定化は知性+医学の目標値10、戦闘中は主行動。医学ファンブルならその治療者は同じ瀕死者へ再試行不可、別人は試せる。

最大22・拘束4・現在2で絶を使わず小休息すると、精神4なら現在6・拘束4。長休息では現在18まで。拘束を解除して現在22になり、二重に回復しない。

**身体＋防御オーラ＋防具**

通常の銃弾には攻撃オーラを加算しない。

銃そのものへ周を使用しても、通常は発射後の弾丸へ念は残らない。

弾丸へ念を維持・付与する場合は、放出系などを利用した専用の発を必要とする。

##### 暫定武器威力

| 武器 | 威力 |
|---|---:|
| 小型拳銃 | 4 |
| 拳銃 | 5 |
| 大型拳銃 | 6 |
| SMG | 5 |
| ライフル | 6 |
| 高威力ライフル | 7 |
| ショットガン近距離 | 7 |
| ショットガン中距離 | 5 |
| 弓 | 4 |
| クロスボウ | 5 |

有効射程を超える射撃は、暫定で命中-2程度。

遮蔽：

- 半遮蔽：回避+2程度
- ほぼ完全な遮蔽：直接射撃不可

##### 投擲武器

投擲は使用者の身体能力が直接影響するため、身体＋攻撃オーラ＋武器補正を使用可能。

##### 自動射撃

以下を暫定候補とし、要テスト。

- 自動射撃可能な武器のみ
- 主行動で宣言
- 命中判定-1
- 命中した場合、命中差による威力補正を1段階上昇
- 通常より多く弾薬を消費


<a id="08-equipment-and-recovery-sec-35"></a>

### 負傷値

出典：Ver.0.2 第35節。

| 負傷値 | 結果 |
|---:|---|
| 0以下 | 有効打なし |
| 1～2 | 軽傷 |
| 3～4 | 負傷 |
| 5～6 | 重傷 |
| 7～8 | 瀕死 |
| 9以上 | 致命傷 |

数値は引き続きテスト対象。


<a id="08-equipment-and-recovery-sec-36"></a>

### 負傷点

出典：Ver.0.2 第36節。

内部的に負傷点として蓄積する。

- 軽傷＝1
- 負傷＝2
- 重傷＝3
- 瀕死＝4

例：

軽傷＋軽傷＝負傷

負傷＋軽傷＝重傷

負傷＋負傷＝瀕死


<a id="08-equipment-and-recovery-sec-37"></a>

### 負傷ペナルティ

出典：Ver.0.2 第37節。

##### 無傷

なし。

##### 軽傷

なし。

##### 負傷

負傷内容に明確に関係する判定へ**-1**。

例：

腕の負傷：
格闘、射撃、手先など。

脚の負傷：
運動、回避など。

##### 重傷

身体・俊敏を使用する判定全般へ**-1**。

負傷部位へ直接関係する判定は使用能力値にかかわらず**-2**を使う。一般の−1とは重ねない。知性の調査、腕を使わない感覚＋念技術の発、交渉など、傷と直接関係しない判定は補正なし。適用は判定前に提示する。

##### 瀕死

原則行動不能。

GMは傷の内容に応じて、個別の状況的ペナルティを設定してよい。


<a id="08-equipment-and-recovery-sec-38"></a>

### 瀕死

出典：Ver.0.2 第38節。

負傷点4に達すると瀕死。

原則行動不能。

瀕死になった瞬間、一度だけ、

**2D6＋身体 vs 10**

で生存判定を行う。

##### 成功

**瀕死・安定**

自然には悪化しない。

ただし瀕死・行動不能のまま。

##### 失敗

**瀕死・危険**

適切な処置が行われないまま十分な時間が経過した場合、死亡する。

何ラウンドで死亡するかを細かく固定せず、戦闘終了・放置時間・状況などからGMが判断する。

##### 致命傷

負傷値9以上の致命傷を受けた場合、生存判定を行わず、最初から**瀕死・危険**となる。


<a id="08-equipment-and-recovery-sec-39"></a>

### 医学

出典：Ver.0.2 第39節。

瀕死・危険のキャラクターへ応急処置を行う場合、

**2D6＋知性＋医学 vs 10**

成功すると、

**瀕死・危険 → 瀕死・安定**

となる。

すでに安定している瀕死者に、応急処置判定を行う必要はない。

戦闘中の応急処置は主行動。

##### 医学ファンブル

応急処置失敗。

さらに、その人物は同じ瀕死者へ再度応急処置を試みることができない。

別の人物は試行可能。

##### 安全な場所での治療

十分な時間と環境がある場合、医学判定成功で負傷点1点を回復。

同じ場所で連続して判定を繰り返して全快させることはできない。

1回の十分な治療につき1回を目安とする。


<a id="08-equipment-and-recovery-sec-40"></a>

### 医療設備

出典：Ver.0.2 第40節。

医療キット：
医学判定+1。

本格的な病院・医療設備：
医学判定+2程度。

または通常では治療できない負傷を治療可能。

瀕死の安定化自体は、医療キットなしでも試行可能。


<a id="08-equipment-and-recovery-sec-41"></a>

### 自然治癒

出典：Ver.0.2 第41節。

目安：

- 軽傷：一晩
- 負傷：数日
- 重傷：1週間以上
- 瀕死：医療必須

細かな日数管理より、シナリオ進行に応じて処理してよい。


<a id="08-equipment-and-recovery-sec-44"></a>

### オーラ回復

出典：Ver.0.2 第44節。

戦闘中の自然回復はない。

##### 通常小休息

10分程度、安全な場所で休息。

**精神点**の現在オーラを回復。

##### 絶による小休息

10分程度、安全な場所で絶を維持して休息。

**精神＋念技術点**の現在オーラを回復。

絶の間は念防御・念による警戒をほぼ失う。

##### 連続休息

同じ消耗に対して、小休息を繰り返して全快することはできない。

戦闘、大きな発使用、長時間の探索など、新しい消耗が発生した後であれば再度使用可能。

##### 長休息

数時間、安全な場所で十分に休息。

現在オーラを最大−拘束まで回復。

拘束中のオーラは、発を解除しない限り戻らない。


<a id="08-equipment-and-recovery-sec-45"></a>

### 現在オーラ0

出典：Ver.0.2 第45節。

即座に気絶はしない。

ただし、

- 新たな発使用不可
- 新たな練・堅・硬など高出力技術使用不可
- 念関連行動に大きな制限

を受ける。

最後の点を支払って成立した練・堅は、その支払いで得た期間まで有効。堅の次の維持時点で不足すれば終了する。既存の持続発も現在0だけでは自動終了せず、有料反復は実行できない。

負傷などを支払ってオーラ不足を補う「限界使用」は採用しない。

## 第9章 成長

シナリオ終了時にGMが成果を確認し、基本3点+追加0～2点を配る。未使用の成長点は記録する。

<a id="09-advancement-a23"></a>

**暫定補足 A23：成長の手続き。** 成長点は持ち越せる。成長チェックによる割引後の費用は最低0点、余った割引は他項目へ移せない。同じ項目を複数段階上げる場合は各段階の費用を順に支払い、チェックはそのうち1段階にまとめて1回だけ使用できる。チェック対象は原文どおり能力値または技能であり、念技術・発は対象に含めない。専門・発の新規取得は物語上の取得理由と容量を確認する。割引を使わないチェックはシナリオ終了処理が終わると消える。

### 成長例

アキラが基本3点+依頼達成1点+追加成果1点=5点を取得。格闘4→5は5点だが、格闘にクリティカルとファンブル両方のチェックがあれば3点で取得し、2点を持ち越す。身体5→6の18点には届かない。格闘に使ったチェックを身体へ移すことはできない。

発の強度3→4は4成長点、構築値も+1。空き容量が0なら成長できず、先に容量を増やすか別の成長を選ぶ。自然な応用は成長点0で、その場で試みてよい。

<a id="09-advancement-sec-46"></a>

### 成長点

出典：Ver.0.2 第46節。

シナリオ終了時、

**基本成長点3点**

を得る。

さらに成果に応じて+0～2点。

目安：

- 主要目的達成：+1
- 大きな追加成果：+1

シナリオ失敗でも基本3点は得る。


<a id="09-advancement-sec-47"></a>

### 成長チェック

出典：Ver.0.2 第47節。

判定でクリティカルまたはファンブルが発生した場合、その判定に使用した、

**能力値または技能のどちらか1つ**

へ成長チェックを入れられる。

クリティカルチェックとファンブルチェックは別管理。

同じ能力値・技能について、

- クリティカルチェック：1シナリオ1回まで
- ファンブルチェック：1シナリオ1回まで

最大2チェック。

一度の判定から能力値と技能の両方へチェックを入れることはできない。


<a id="09-advancement-sec-48"></a>

### 成長チェックの効果

出典：Ver.0.2 第48節。

シナリオ終了時、その項目を成長させる場合、

**チェック1個につき必要成長点-1。**

両方あれば-2。

成長チェックは持ち越し不可。

そのシナリオ終了時に使用しなければ消滅する。

|---|---:|

| 4→5 | 5 |

ただし、シナリオ経験や訓練など、取得理由を必要とする。

<a id="09-advancement-sec-53"></a>

### 発の成長

出典：Ver.0.2 第53節。

#### 自然な応用

**0点。**

同一能力原理から自然に導ける新しい使い方は、成長点なしで試してよい。

#### 強度上昇

| 成長 | 必要点 |
|---|---:|
| 1→2 | 2 |
| 2→3 | 3 |
| 3→4 | 4 |
| 4→5 | 5＋相応の制約等 |
| 5→6 | 6以上＋非常に重い制約等 |

強度上昇によって構築値も増加する。

所有する全発の構築値合計が発容量を超える場合、その成長はできない。

#### 射程・範囲・持続の拡張

**構築値+1となる拡張につき2成長点**

を暫定基準とする。

#### 新しい効果の追加

既存発へ、能力原理から自然には導けない新効果を追加する場合、

**増加した構築値×2成長点**

を基準とする。

#### 新しい独立発

**5～8成長点程度**

さらに、訓練・経験・覚醒などシナリオ上の取得理由を必要とする。

目安：

- 単純な発：5
- やや複雑：6
- 高度・特殊：7～8

発容量に十分な空きも必要。

#### オーラ消費効率

特定の発について、

**消費オーラ-1＝5成長点**

最低消費1。

構築値そのものは減少しない。

#### 発容量拡張

念技術上昇によって発容量も自然に増加する。

さらに、

**5成長点で発容量+1**

最大+3までの追加容量を暫定上限とする。

## 第10章 GMガイド

### セッション前

初回は[導入シナリオ](../scenarios/01-missing-cargo-gm.md)を読み、サンプルPCと敵の配分・発を確認する。全員で暫定補足を含む本書を使うと確認する。未定義の発は戦闘前に行動・抵抗・終了を決める。原作の再現より、参加者が行動を選べる情報を優先する。

### 難易度と対抗

目標値7/9/11/13/15を基準に、状況と結果から選ぶ。能力値・技能の合計が高ければ普通の判定は成功しやすい。得意な行動を毎回目標値引き上げで相殺しない。不可能なら判定させず、何があれば可能になるかを説明する。相手が積極的に阻止するなら対抗判定にし、受動側が誰かを振る前に確認する。

### 発の裁定

同じ原理からできる工夫は認める。規模、強度、届く距離、持続を上限とし、独立した効果を追加するなら構築を見直す。迷った裁定はその場の結論・理由をメモしてシナリオ後に相談し、既存数値や設計の変更をそのまま恒久ルールにしない。

能力情報は、まず見える現象を示し、調査で条件の手掛かり、検証で実際の条件を開示する。敵の能力を秘密にするために宣言後に条件を足さない。GMは非公開の配分も先に記録する。

### 敵の作り方

<a id="10-gm-guide-a24"></a>

**暫定補足 A24：NPCの簡略作成。** PCと同じ21点・技能25点に揃える必要はない。必要な能力値、命中・回避の能力と技能、念技術、資源、発容量と発、配分、装備、負傷、動機、撤退条件を記入する。記載のない技能は0。NPCも行動・消費・対抗・負傷の共通ルールに従う。発を使うなら構築と容量を確認する。原作人物の強さを数値へ忠実に変換する必要はない。

敵は人数を増やすほど主行動が増える。初回はPC人数以下の敵を使い、敵を倒す以外にも交渉・逃走・目的物回収で終われる状況を作る。未経験の卓では高強度操作や致命傷を狙う敵から始めない。

### 終了後

報酬と成長を処理し、分かりにくかった箇所、使えなかった技能、発の消費、負傷の頻度、決着までのラウンドを記録する。[調整課題](../design/open-questions.md)へ追加する。机上検証と実卓での検証は区別する。
