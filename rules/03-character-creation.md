# 第3章 キャラクター作成

[シート](../play/character-sheet.md)を複製し、次の順番で記入する。完成例は[サンプルPC](../play/sample-characters.md)。

<a id="a04"></a>

1. 名前、目的、仲間と協力する理由、得意なことを決める。全員、念を習得済み。ハンター資格の有無は設定で決める。
2. 下記の方法で能力値を合計21点、各1～6にする。
3. [技能](02-checks.md)に25点を配分する。**暫定補足 A04：初期取得**として1点につき技能値+1、未取得0、各上限4とする。成長時の必要点とは別である。
4. 専門分野を2つ、広すぎない分野名で取得する。「あらゆる念」「戦闘全般」ではなく「港湾物流」「毒物」のように具体化する。
5. 念技術3、[念系統](04-nen.md)を決める。1D6なら強化・変化・放出・具現化・操作・特質を順に1～6へ対応させる（暫定補足 A04）。
6. 最大オーラ=10+精神×3、現在オーラ=最大、拘束オーラ0、発容量=8+念技術=11、負傷点0、成長点0を記入する。
7. [発の作成](05-hatsu.md)に従い発を作り、全発の構築値合計を容量以内にする。GMと性能・消費・行動・抵抗・解除を合意する。**暫定補足 A04**として初期の発取得に成長点は使わない。
8. [装備](08-equipment-and-recovery.md)から持ち物を相談して決め、攻撃と回避の式を書く。**暫定補足 A04**として初期は標準武器1つまたは拳銃1丁、軽防具、職業上の道具、通信端末を基本とし、買い物や通貨の細かな管理は行わない。医療担当は医療キットを持てる。
9. 戦闘開始時の配分案（例2/2/1）を書き、仲間と役割を相談する。

## 完成チェック

能力値合計21、技能合計25・各4以下、専門2つ、念技術3、オーラ式、発容量11以内を確認する。発の「能力原理」「できないこと」「自然な応用」「隠す情報」も言葉で説明できれば完成。

## 能力値

出典：Ver.0.2 第4節。

能力値は6種類。

- 身体
- 俊敏
- 感覚
- 知性
- 精神
- 社交

値は1～6。

能力値合計は**21**。

#### 能力値の目安

| 値 | 目安 |
|---:|---|
| 1 | 非常に不得手 |
| 2 | やや不得手 |
| 3 | 平均的 |
| 4 | 得意 |
| 5 | 非常に優秀 |
| 6 | 卓越 |

#### ポイント作成

6能力へ合計21点を割り振る。

各能力値は1～6。

#### ランダム作成：基本方式

5D6を振る。

6つ目の値を、

**21－最初の5個の合計**

とする。

6つ目が1～6に収まらなかった場合は、5D6すべてを振り直す。

得られた6つの数字は、好きな能力値へ自由に割り振る。

#### ランダム作成：選択ルール

全能力を1から開始する。

残り15点について15D6を振り、

- 1＝身体
- 2＝俊敏
- 3＝感覚
- 4＝知性
- 5＝精神
- 6＝社交

として対応する能力を+1する。

すでに6になっている能力が出た場合、そのダイスだけ振り直す。
