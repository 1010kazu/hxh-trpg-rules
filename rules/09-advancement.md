# 第9章 成長

シナリオ終了時にGMが成果を確認し、基本3点+追加0～2点を配る。未使用の成長点は記録する。

<a id="a23"></a>

**暫定補足 A23：成長の手続き。** 成長点は持ち越せる。成長チェックによる割引後の費用は最低0点、余った割引は他項目へ移せない。同じ項目を複数段階上げる場合は各段階の費用を順に支払い、チェックはそのうち1段階にまとめて1回だけ使用できる。チェック対象は原文どおり能力値または技能であり、念技術・発は対象に含めない。能力値+念技術の判定で特殊出目が出た場合、使用した能力値へチェックを付けられる。専門・発の新規取得は物語上の取得理由と容量を確認する。割引を使わないチェックはシナリオ終了処理が終わると消える。

## 成長例

アキラが基本3点+依頼達成1点+追加成果1点=5点を取得。格闘4→5は5点だが、格闘にクリティカルとファンブル両方のチェックがあれば3点で取得し、2点を持ち越す。身体5→6の18点には届かない。格闘に使ったチェックを身体へ移すことはできない。

発の強度3→4は4成長点、構築値も+1。空き容量が0なら成長できず、先に容量を増やすか別の成長を選ぶ。自然な応用は成長点0で、その場で試みてよい。

<a id="sec-46"></a>

## 成長点

出典：Ver.0.2 第46節。

シナリオ終了時、

**基本成長点3点**

を得る。

さらに成果に応じて+0～2点。

目安：

- 主要目的達成：+1
- 大きな追加成果：+1

シナリオ失敗でも基本3点は得る。


<a id="sec-47"></a>

## 成長チェック

出典：Ver.0.2 第47節。

判定でクリティカルまたはファンブルが発生した場合、その判定に使用した、

**能力値または技能のどちらか1つ**

へ成長チェックを入れられる。

クリティカルチェックとファンブルチェックは別管理。

同じ能力値・技能について、

- クリティカルチェック：1シナリオ1回まで
- ファンブルチェック：1シナリオ1回まで

最大2チェック。

一度の判定から能力値と技能の両方へチェックを入れることはできない。


<a id="sec-48"></a>

## 成長チェックの効果

出典：Ver.0.2 第48節。

シナリオ終了時、その項目を成長させる場合、

**チェック1個につき必要成長点-1。**

両方あれば-2。

成長チェックは持ち越し不可。

そのシナリオ終了時に使用しなければ消滅する。

## 技能成長

出典：Ver.0.2 第49節。

| 成長 | 必要点 |
|---|---:|
| 0→1 | 1 |
| 1→2 | 1 |
| 2→3 | 2 |
| 3→4 | 3 |
| 4→5 | 5 |


<a id="sec-50"></a>

## 専門分野の取得

出典：Ver.0.2 第50節。

新しい専門分野：

**2成長点**

ただし、シナリオ経験や訓練など、取得理由を必要とする。


<a id="sec-51"></a>

## 能力値成長

出典：Ver.0.2 第51節。

**次の能力値×3点**

例：

3→4：12点

5→6：18点

最大6。


<a id="sec-52"></a>

## 念技術成長

出典：Ver.0.2 第52節。

**次の念技術×4点**

例：

3→4：16点

4→5：20点

5→6：24点

最大6。


<a id="sec-53"></a>

## 発の成長

出典：Ver.0.2 第53節。

### 自然な応用

**0点。**

同一能力原理から自然に導ける新しい使い方は、成長点なしで試してよい。

### 強度上昇

| 成長 | 必要点 |
|---|---:|
| 1→2 | 2 |
| 2→3 | 3 |
| 3→4 | 4 |
| 4→5 | 5＋相応の制約等 |
| 5→6 | 6以上＋非常に重い制約等 |

強度上昇によって構築値も増加する。

所有する全発の構築値合計が発容量を超える場合、その成長はできない。

### 射程・範囲・持続の拡張

**構築値+1となる拡張につき2成長点**

を暫定基準とする。

### 新しい効果の追加

既存発へ、能力原理から自然には導けない新効果を追加する場合、

**増加した構築値×2成長点**

を基準とする。

### 新しい独立発

**5～8成長点程度**

さらに、訓練・経験・覚醒などシナリオ上の取得理由を必要とする。

目安：

- 単純な発：5
- やや複雑：6
- 高度・特殊：7～8

発容量に十分な空きも必要。費用5～8の選択理由を設計時に合意し、能力原理・行動・系統・解除条件の独立性を確認する。同じ原理の自然な応用は0点。新発と既存発の追加効果を取得費用だけのために分けたりまとめたりしない。

### オーラ消費効率

特定の発について、

**消費オーラ-1＝5成長点**

最低消費1。

構築値そのものは減少しない。

### 発容量拡張

念技術上昇によって発容量も自然に増加する。

さらに、

**5成長点で発容量+1**

最大+3までの追加容量を暫定上限とする。念技術の成長による自然増加と追加拡張を別に記録する。同じ終了処理で拡張を先に購入してから発を成長させられる。各段階で容量内であることを確認する。
