# 第7章 戦闘

開始前に[念技術](04-nen.md)と[装備・負傷](08-equipment-and-recovery.md)を参照。攻撃が命中しただけでは負傷点は決まらず、威力と防護を比べて負傷値を算出する。

## 手番の手順

<a id="a16"></a>

**暫定補足 A16：戦闘の時間処理。** 開始時に配置と通常5段階の配分を決め、行動順を振る。行動順が同値なら俊敏が高い方、それも同じなら該当者だけ1D6を振り直す。全員が1回動くとラウンド終了。開始時と自分の手番開始時にリアクション1回を得て、残りは繰り越さない。初手前にも1回使える。

手番開始時に硬の変更不能を終了し、堅の維持・終了を決める。主行動・補助行動・通常移動は好きな順で行い、未使用分は持ち越せない。1回の移動を主行動の前後に分割しない。主行動で攻撃、発、凝、脱出、応急処置、協力などを行う。宣言→対象側の対応宣言→消費→判定→威力・負傷→効果終了の順で処理する。流のリアクションは出目を見る前に宣言する。主行動と同じ行動を補助行動で行うことはできない。

<a id="a17"></a>

**暫定補足 A17：移動と接敵。** 通常移動1回で同じ部屋・近距離内の地点へ移動できる。別の近距離区画へ移るには通常移動に加えて主行動を使う。GMは戦闘前に地図上の区画を示す。移動自体には判定不要、障害や危険があるときは運動等で判定。接触攻撃は手が届く相手のみ。移動から自動的な機会攻撃は発生しない。遮蔽・落差・障害は状況に応じてGMが宣言する。

<a id="a18"></a>

**暫定補足 A18：発攻撃と抵抗。** 発攻撃の負傷値は発威力+命中差補正−通常の防護値。攻撃オーラを発威力へ追加しない。通常近接攻撃との併用は高い威力1つを用い、両方を足さない。拘束・操作はまず回避との命中対抗、命中後に記載された成立対抗。自動命中でも成立対抗は省略しない。脱出時は拘束側も再び振る。操作を受けた者の手番で命令を実行し、操作強度・抵抗機会・終了条件は発シートに明記する。

## 1ラウンドの例

[サンプルPC](../play/sample-characters.md)のアキラは身体5、格闘4、標準武器+1。初期配分2/2/1から、手番の流で3/1/1へ1段階動かす（自動成功）。出目7で命中16。敵の回避は出目6+俊敏3+回避2=11。命中差5で威力補正+2。

打撃値=身体5+攻撃3+武器1=9。敵の防護=身体3+防御2+軽防具1=6。負傷値=9+2−6=5で重傷、負傷点3。敵は身体・俊敏全般−1、負傷部位に直接関係するなら−2（合計−3にはしない）。敵が降参すれば戦闘終了。戦うなら同じラウンドの自分の手番に行動できる。

### 流・硬の例

2/2/1→4/1/0は移動量2、俊敏+念技術の目標値10。通常失敗なら宣言した移動のうち1段階を選び3/1/1または3/2/0へ。ファンブルなら2/2/1のまま。

硬なら堅・練を終了し5/0/0へ。アキラの通常近接の打撃値は5+5+1+硬2=13。発強度3・念技術3なら発威力は3+3+硬2=8であり、さらに攻撃5を足さない。硬後は次の自分の手番まで防御0、流のリアクションも不可。その他枠を使う周の+1と硬の+2は重複しない。

<a id="sec-26"></a>

## 戦闘ラウンド

出典：Ver.0.2 第26節。

各キャラクターは、自分の手番に、

- 主行動1回
- 補助行動1回
- 通常移動1回

を行う。

さらに次の自分の手番まで、

**リアクション1回**

を使用可能。

通常の回避はリアクションを消費しない。


<a id="sec-27"></a>

## 行動順

出典：Ver.0.2 第27節。

戦闘開始時に一度だけ、

**2D6＋俊敏**

を判定する。

高い順に行動し、原則として戦闘終了まで順番を固定する。

毎ラウンドの振り直しは現時点では採用しない。


<a id="sec-28"></a>

## オーラ配分

出典：Ver.0.2 第28節。

通常時、戦闘中は、

- 攻撃
- 防御
- その他

へ合計**5段階**を配分する。

例：

攻撃2／防御2／その他1。

通常は公開情報。

隠を使用すると非公開にできる。


<a id="sec-29"></a>

## 通常攻撃

出典：Ver.0.2 第29節。

#### 近接

**2D6＋身体または俊敏＋格闘**

#### 射撃

**2D6＋俊敏または感覚＋射撃**

#### 回避

**2D6＋俊敏＋回避**

攻撃側が防御側を上回れば命中。

同値なら回避側が勝つ。


<a id="sec-30"></a>

## 命中差

出典：Ver.0.2 第30節。

| 命中差 | 威力補正 |
|---:|---:|
| 1～2 | +0 |
| 3～4 | +1 |
| 5～6 | +2 |
| 7以上 | +3 |


<a id="sec-31"></a>

## 通常近接攻撃の威力

出典：Ver.0.2 第31節。

**打撃値＝身体＋攻撃オーラ＋武器補正等**

**防護値＝身体＋防御オーラ＋防具補正等**

**負傷値＝打撃値＋命中差補正－防護値**


<a id="sec-32"></a>

## 発による攻撃

出典：Ver.0.2 第32節。

暫定的に、

**発威力＝攻撃強度＋念技術**

命中判定は能力内容に適した能力値・技能を使用する。

例：

接触型：
身体または俊敏＋格闘

放出弾：
感覚＋念技術

通常攻撃と攻撃発の威力は原則加算せず、高い方または発側を使用する。

硬と組み合わせた場合は発威力+2。


<a id="sec-42"></a>

## 拘束

出典：Ver.0.2 第42節。

命中判定と、効果成立判定の2段階。

拘束側：

**2D6＋拘束強度＋念技術**

抵抗側：

**2D6＋身体＋念技術**

同値なら抵抗側が勝つ。

強度3程度では即行動不能にはしない。

代表的な拘束状態：

- 移動不可
- 身体・俊敏を使う行動へ不利
- 発は能力内容次第で使用可能

脱出は主行動。

再度対抗判定を行う。


<a id="sec-43"></a>

## 操作

出典：Ver.0.2 第43節。

命中判定と効果成立判定の2段階。

操作側：

**2D6＋操作強度＋念技術**

抵抗側：

**2D6＋精神＋念技術**

同値なら抵抗側が勝つ。

自傷、仲間への攻撃、自殺など、本人の重大な利益に反する命令はより高い強度を必要とする。

完全操作は原則として強度5～6＋厳しい発動条件等を必要とする。
