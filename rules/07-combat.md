# 第7章 戦闘

開始前に[念技術](04-nen.md)と[装備・負傷](08-equipment-and-recovery.md)を参照。攻撃が命中しただけでは負傷点は決まらず、威力と防護を比べて負傷値を算出する。

## 手番の手順

<a id="a16"></a>

**暫定補足 A16：戦闘の時間処理。** Ver.0.5では以下を共通手順とする。

### 開戦と手番

開戦時に配置と通常5段階の配分を決め、2D6＋俊敏で行動順を決める。同値なら素の俊敏、高い1D6の順で比較し、再同値の組だけ振り直す。戦闘中は順番を固定する。途中参加者は参加時に振り、解決中の行動を終えてから順番へ挿入する。挿入位置が過ぎていれば次ラウンドから手番を得る。参加時の位置は直前の行動と入口からGMが示す。

開戦・参加時にリアクション1回を得る。自分の初手前にも使える。自分の手番開始時は次の順で処理する。

1. 練の追加2段階を除き、硬の配分固定を解除する。維持する技術の占有条件を満たす配分へ戻し、必要枠を失った技術を終了する。
2. 堅の維持費を支払うか終了する。
3. リアクションを1回へ更新する。残数は持ち越さない。

主行動・補助行動・通常移動は任意の順で、それぞれ解決してから次へ進む。主行動で攻撃、発、凝、脱出、応急処置、協力などを行う。補助行動を主行動の代用にはできない。通常移動を主行動の前後に分割しない。流は自分の手番に行動不要で1回。任意解除は各効果が認める時点で行い、他の行動の解決中には割り込まない。練を補助行動で開始し、その手番の主行動に硬を使える。

手番終了時に未使用の主行動・補助行動・移動を失い、該当する持続満了を処理する。全員の手番位置を通過したらラウンド末。反復効果のラウンド回数を更新する。練は次の自分の手番開始まで維持する。硬の固定中に練が切れた場合は追加2段階だけを除き、残りの配分を次の自手番まで保つ。

### 行動の宣言と解決

1. 仮宣言で行動、対象、性能、経路を示す。
2. 対象認識・条件・行動枠・必要資源を確認する。発の初回反復を行うならその費用も含める。
3. 宣言を確定する。
4. 対象側が対応を宣言する。
5. 各効果の定義に従って消費と対応を解決する。
6. 命中・抵抗等を判定する。
7. 威力・防護・負傷・状態を適用する。
8. 終了条件を確認する。

宣言確定後は相手の対応を見て対象・性能を変更したり撤回したりできない。対応で対象が離脱しても確定した費用を再計算しない。発動前の資源不足では行動枠・オーラを消費しない。公開情報で分かる不足は仮宣言中に調整できる。GMが秘匿条件を照合して発動不可を伝えた場合、同じ手番で発の再宣言は1回まで。再度不可なら未使用の主行動を発以外に使える。自動識別型複合発は公開・秘匿を問わず再宣言1回までとする。

単発消費・発動消費は判定失敗でも戻らない。持続分は[発の使用](05-hatsu.md#a11)で定めた成立時に拘束し、持続自体が不成立なら確保済み分を返す。未発生の初回反復は請求しない。成立後の反復が外れた場合は反復消費が残る。

### 対応と行動不能

通常回避はリアクション不要。各キャラクターが同じ攻撃に使えるリアクションは原則1回で、流と瞬間防御を重ねられない。対応は攻撃の出目前に確定し、流の配分変更を先に解決してから命中・回避を判定する。持続中の防護や障壁は適用条件内なら対応枠を使わない。硬の固定中は流で動かせず、通常回避と配分変更を伴わない適法な対応は使える。

拘束で制限される行動はその発に従う。脱出に主行動を使って成功すれば、未使用かつ実行可能な補助行動・通常移動を続けられる。手番前から行動不能なら行動枠を使えない。手番途中で行動不能になった場合、原因となった処理と成立済みの効果を適用し、続行不能な行動を打ち切る。行動不能中は能動回避・リアクションを行えない。瀕死・安定も原則行動不能。飛ばした手番を取り直さず、その手番位置で持続満了を確認する。気絶時の発は設計済みの維持条件に従う。

<a id="a17"></a>

**暫定補足 A17：移動と接敵。** GMは開戦時に区画、通行可能な接続、初期位置、把握できる障害・遮蔽・距離帯を示す。単純な場は1区画とし、移動や射線の選択に影響する地形で区画を分ける。区画内の位置も接触や遮蔽に影響する。

通常移動1回で通行できる同一区画内の地点へ移動する。徒歩で別区画へ移るには、通常移動＋主行動を同時に使い、直接接続する1区画へ移る。経路と到達点を宣言する。平易な移動は判定不要。移動中に越えられる難所なら技能・目標値・失敗時に止まる位置と危険を宣言確定前にGMが示す。別の作業が必要な障害は先に解決する。主行動で扉を開けた手番は、通常移動だけで別区画へ渡れない。失敗・中断でも確定済みの移動枠を消費し、最後の到達地点を記録する。発の追加移動・運搬は個別条件に従う。

手が届く位置に到達したら接触攻撃ができる。離脱で自動機会攻撃は発生しない。発に定義した手番外反応はA16で解決する。移動不可の拘束から脱出した手番は、未使用の通常移動で同一区画内を動ける。

[距離帯](05-hatsu.md#a12)は射程と消費を決め、区画の徒歩接続と別に示す。射程内でも対象認識と経路を確認する。半遮蔽は射撃への回避＋2程度、ほぼ完全な遮蔽は直接射撃不可。認識・遮蔽を越える性能、範囲の起点・対象選別は発の設計に従う。途中参加だけで追加移動や接敵は得られず、参加時の対応枠は以後の行動に使う。

<a id="a18"></a>

**暫定補足 A18：発攻撃と抵抗。** 発シートに命中式・対象・行動・抵抗・適用条件を記す。

### 命中・防護・障壁

回避可能な対象とは通常の命中対抗を行い、射撃型の発には経路に応じた遮蔽を適用する。対応で射程・範囲外へ出たり経路が塞がった対象には効果を適用しない。通常同値は回避側勝利。[特殊出目](02-checks.md#a03)を優先する。

無人の固定物や行動不能の対象には能動回避を振らせない。届くことが明らかなら命中を省略し、命中差補正＋0。精度が不確実ならGMが既存の難易度を事前提示して命中判定を行い、この場合も標準の命中差補正は＋0。振った攻撃がクリティカルなら威力補正は最低＋2。防護・障壁・成立抵抗の適用条件は個別に確認する。 固定物の半遮蔽は精密判定の目標値に＋2を適用する。回避対抗の遮蔽補正と同じ遮蔽を重ねない。ほぼ完全な遮蔽で射線が通らなければ直接射撃はできない。

物体の位置・材質・大きさと破壊に必要な威力・条件を宣言確定前にGMが示す。固定物へ術者の身体・防御オーラを自動適用しない。能動的に保持して守れる携行物は保持者の回避との対抗を使い、宣言した物体だけを対象とする。物体への命中を人物の負傷へ転用しない。破壊により維持条件を失った発は終了し、その拘束オーラだけを返す。

発攻撃の負傷値は発威力＋命中差補正−通常防護値。攻撃オーラや通常武器の補正を発威力へ加えない。同じ打撃で通常近接と攻撃発を併用する場合は、使用条件を満たす高い基礎威力1つを使い、命中差と硬の補正を各1回適用する。通常側を選んでも確定した発の費用は残る。

[防御発](05-hatsu.md#a14)の防護強化・瞬間防御を適用する。同種補正は最大値。障壁は命中確認後に経路ごとに比較し、攻撃威力＋命中差補正が防御強度＋術者の念技術を上回れば通過、同値以下は遮断。通過時は障壁値を減算せず通常防護を1回適用する。同経路の同種障壁は最大値、別地点は通過順に比較する。障壁を破壊する攻撃で背後へ同時命中はしない。威力のない拘束・操作にも遮断は働き、突破威力や別経路を備えるかは設計時に定める。

### 成立・脱出・操作

拘束・操作は命中と到達の後に各節の成立対抗を行う。自動命中・回避不能でも成立対抗は省略しない。防御オーラ・防具・命中差は成立式へ加えない。攻撃と拘束が付随する場合、負傷値0以下でも到達していれば設計上の条件に従って成立対抗を行う。同じ攻撃で新たにつく負傷補正を、その攻撃自身の成立対抗に遡って適用しない。

脱出は主行動で双方が新たに振る。通常同値は拘束側勝利で状態維持。成功時の返還はその発の終了条件に従う。

操作は成立時に有効となり、命令は対象が次に該当枠を使える自分の手番で実行する。進行中の処理を遡らず、残る該当枠だけを使う。追加の行動枠を得ず、実行不能な命令には枠を消費しない。命令変更、重大な利益に反する命令、再抵抗機会、終了、他操作の上書き性能は設計時に合意する。標準では毎手番の無料再抵抗を与えない。相容れない命令は先に成立したものを優先し、後の命令は競合中の枠を使えない。後の操作が残っていれば競合解消後の該当枠で実行できる。

### 複数対象

同一の範囲・複数対象攻撃は、攻撃側の命中用2D6を1回振り、対象ごとに経路・遮蔽・回避を計算する。同じ強度・同じ効果の成立判定も術者側の出目を共有し、対象は個別に抵抗する。独立した攻撃や別種の効果は設計に従って別判定。特殊出目は共有する。

対応は出目前に確定し、同一効果の判定には解決時点の状態を用いる。その攻撃が生む負傷・拘束で未処理の対象の判定を遡って変えない。回避・抵抗の成功人数で共通費用を再計算しない。対象付与型で「少なくとも1人に成立」が持続条件なら、全員不成立では確保せず、一部成立では成立対象だけに残る。先に持続領域が成立した場合は、全員が抵抗しただけでは領域を終了しない。

## 1ラウンドの例

[サンプルPC](../play/sample-characters.md)のアキラは身体5、格闘4、標準武器+1。初期配分2/2/1から、手番の流で3/1/1へ1段階動かす（自動成功）。出目7で命中16。敵の回避は出目6+俊敏3+回避2=11。命中差5で威力補正+2。

打撃値=身体5+攻撃3+武器1=9。敵の防護=身体3+防御2+軽防具1=6。負傷値=9+2−6=5で重傷、負傷点3。敵は身体・俊敏全般−1、負傷部位に直接関係するなら−2（合計−3にはしない）。敵が降参すれば戦闘終了。戦うなら同じラウンドの自分の手番に行動できる。

<a id="controlled-attack"></a>

### 選択ルール・手加減

この選択ルールを使うかは開始前に卓で決める。攻撃者は、通常攻撃または負傷を与える発の宣言確定前に手加減を宣言できる。通常の命中・防護・特殊出目を処理した後、その攻撃による最終負傷値の上限を6とする。クリティカルでも上限は6。攻撃結果を見てから変更できず、行動・オーラの消費は通常どおり。

負傷点の累積、4点到達時の生存判定、瀕死への追加有効打は通常どおり処理する。救命が必要になる可能性は残る。GMは攻撃確定前に、観察できる負傷表現・既に判明した情報と、救命が必要になり得る危険を示す。秘匿している正確な負傷点を自動開示する規則にはしない。降参・拘束・武器放棄・目的物回収・救命役への協力も選べる場面を用意する。手加減は負傷値だけに適用し、拘束・操作や環境そのものによる危険の条件は変えない。範囲攻撃の手加減はその宣言で与える負傷全体へ適用する。継続する発の反復攻撃は各回の宣言で選ぶ。

### 流・硬の例

2/2/1→4/1/0は移動量2、俊敏+念技術の目標値10。通常失敗なら宣言した移動のうち1段階を選び3/1/1または3/2/0へ。ファンブルなら2/2/1のまま。

硬は堅を終了し、維持する周の1段階を残して4/0/1へ集中する。アキラの周付き標準武器では打撃値は5+4+1+硬1=11。周の威力＋1は重ねない。練を併用すれば6/0/1、打撃値は5+6+1+硬2=14。5段階以上を集中できる素手の硬で、発強度3・念技術3なら発威力は3+3+硬2=8であり、さらに攻撃5を足さない。硬後は次の自分の手番まで防御0、流のリアクションも不可。その他枠を使う周の+1と硬の+2は重複しない。

## 戦闘ラウンド

出典：Ver.0.2 第26節。

各キャラクターは、自分の手番に、

- 主行動1回
- 補助行動1回
- 通常移動1回

を行う。

さらに次の自分の手番まで、

**リアクション1回**

を使用可能。

通常の回避はリアクションを消費しない。


<a id="sec-27"></a>

## 行動順

出典：Ver.0.2 第27節。

戦闘開始時に一度だけ、

**2D6＋俊敏**

を判定する。

高い順に行動し、原則として戦闘終了まで順番を固定する。

毎ラウンドの振り直しは現時点では採用しない。


<a id="sec-28"></a>

## オーラ配分

出典：Ver.0.2 第28節。

通常時、戦闘中は、

- 攻撃
- 防御
- その他

へ合計**5段階**を配分する。

例：

攻撃2／防御2／その他1。

通常は公開情報。

隠を使用すると非公開にできる。

## 通常攻撃

出典：Ver.0.2 第29節。

#### 近接

**2D6＋身体または俊敏＋格闘**

#### 射撃

**2D6＋俊敏または感覚＋射撃**

#### 回避

**2D6＋俊敏＋回避**

攻撃側が防御側を上回れば命中。

同値なら回避側が勝つ。

<a id="sec-32"></a>

## 発による攻撃

出典：Ver.0.2 第32節。

暫定的に、

**発威力＝攻撃強度＋念技術**

命中判定は能力内容に適した能力値・技能を使用する。

例：

接触型：
身体または俊敏＋格闘

放出弾：
感覚＋念技術

通常攻撃と攻撃発の威力は原則加算せず、使用条件を満たす高い方1つを使用する。

硬と組み合わせる場合は[硬の集中段階に応じた補正](04-nen.md#sec-11)を1回加える。


<a id="sec-42"></a>

## 拘束

出典：Ver.0.2 第42節。

命中判定と、効果成立判定の2段階。

拘束側：

**2D6＋拘束強度＋念技術**

抵抗側：

**2D6＋身体＋念技術**

同値なら抵抗側が勝つ。

強度3程度では即行動不能にはしない。

代表的な拘束状態：

- 移動不可
- 身体・俊敏を使う行動へ不利
- 発は能力内容次第で使用可能

脱出は主行動。

再度対抗判定を行う。


<a id="sec-43"></a>

## 操作

出典：Ver.0.2 第43節。

命中判定と効果成立判定の2段階。

操作側：

**2D6＋操作強度＋念技術**

抵抗側：

**2D6＋精神＋念技術**

同値なら抵抗側が勝つ。

自傷、仲間への攻撃、自殺など、本人の重大な利益に反する命令はより高い強度を必要とする。

完全操作は原則として強度5～6＋厳しい発動条件等を必要とする。
