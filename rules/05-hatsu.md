# 第5章 発の作成

念能力はリストから選ぶ魔法ではなく、能力原理から設計する。まず「何を実現するか」「どんな仕組みか」を1～2文で書き、[発シート](../play/hatsu-sheet.md)を埋める。

## 設計から使用まで

1. 主効果と強度を選び、必要な系統を列挙する。原理から自然な応用と、独立した追加効果を分ける。
2. 最大射程・範囲・持続・特殊性を決める。複合効果があれば追加分と共通項を分けて計算する。
3. 系統適性は使用系統ごとに1回加え、全発の構築値合計を発容量以内にする。
4. 強度5～6の根拠になる条件、代償、誓約と違反結果をGMと決める。構築値は割り引かない。
5. 行動、判定、抵抗、成立効果、消費または拘束、持続終了、再使用・解除条件を記入する。
6. 最大性能での構築値と、今回使う性能での消費を区別する。

## 暫定補足による使用手順

<a id="a11"></a>

**暫定補足 A11：発の行動と失敗。** 特記しない発の使用は主行動。届く対象と性能を宣言し、現在オーラを支払う、または拘束してから判定する。外れた単発は返金しない。持続発が成立しなかった場合はその行動終了時に解除し拘束を返すが、主行動は戻らない。抵抗不要の自分用効果は原則判定不要。持続の数ラウンドは設計時に2～5のどれかを決め、発動手番を1回目と数え、指定回数目の自分の手番終了時に切れる。任意解除は自分の手番で行動不要。他者の能力は解除できない。

<a id="a12"></a>

**暫定補足 A12：距離と規模。** 本書の初期設定は接触=手が届く、近距離=同じ部屋、中距離=隣の部屋や同じ通り、長距離=見通せる遠方、超遠距離=その外側。小範囲=部屋の一部、広範囲=部屋全体、非常に広範囲=建物以上。地形による違いは宣言前にGMが示す。指定する複数対象は最大数を、範囲効果は境界と味方を巻き込むかを設計時に決める。射程内でも認識できない対象への直接指定は原則不可。効果自体が探知・自動反応を備える場合はその設計に従う。

<a id="a13"></a>

**暫定補足 A13：複合発の消費。** 選択式は今回選んだ効果の強度を使う。同時発生式は今回発生する各効果の強度を合計し、共通の射程・範囲は1回だけ加える。治療を含むなら治療の追加消費+1も加える。維持だけで攻撃・治療を繰り返せない。反復型は設計時に「維持の拘束」と「効果発生ごとの追加消費・行動」を分けて決める。

<a id="a14"></a>

**暫定補足 A14：数値未定義の効果。** 防御・強化・隠蔽・生成等は強度だけで共通の数値式を推測せず、影響する判定・加算値・重複・突破条件をGMと設計時に合意する。例はサンプル発を参照。新しい性能や通常ルールを覆す効果は、自然な応用に含めず構築へ戻る。拘束や操作の対抗を省略して成功にすることはできない。

## 構築と拘束の計算例

変化系が「粘着糸」を作る。拘束強度3+近距離1+単体0+3ラウンド1+特殊性0+変化適性0=構築値5。相手を捕らえるときは現在4を拘束へ移す。糸を手すりに結び付けて体を支える用途は同じ原理の自然な応用。転移や記憶読取は糸の説明だけでは増やせない。

最大オーラ22、現在22から拘束4で現在18・拘束4。さらに練で2消費すれば現在16・拘束4。糸を解除すると現在20・拘束0。休息しても現在+拘束が22を超えることはない。

<a id="sec-12"></a>

## 発容量

出典：Ver.0.2 第12節。

**発容量＝8＋念技術＋容量拡張**

念技術3なら基本発容量11。

発容量は、**所有するすべての発の構築値合計の上限**である。

例：

発A：構築値5  
発B：構築値4  

なら合計9。

発容量11なら取得可能。

軽い発を複数持つことも、一つの複雑・特殊な発へ容量の大半を使うこともできる。


<a id="sec-13"></a>

## 発の作成

出典：Ver.0.2 第13節。

最初に能力コンセプトを決める。

その後、

- 使用系統
- 基本効果
- 強度
- 射程
- 対象・範囲
- 持続
- 特殊性
- 制約
- 代償
- 誓約

を設定する。

**柔軟性そのものには構築値を要求しない。**

同じ能力原理から自然に導ける応用は、追加構築値なしで自由に試みてよい。

例：

「粘着性の糸」を作る発なら、

- 拘束
- 物を引く
- 糸を壁へ付けて移動
- 糸を張って振動を察知
- 足場として利用

などは、能力原理から自然なら追加構築値を要求しない。

能力原理から説明できない新しい効果には、追加構築値が必要。

<a id="sec-15"></a>

## 発の強度

出典：Ver.0.2 第15節。

強度1～6。

| 強度 | 基準 |
|---:|---|
| 1 | 小さな効果 |
| 2 | 実用的 |
| 3 | 一般的な念能力者の主力 |
| 4 | 強力 |
| 5 | 非常に強力 |
| 6 | 通常限界を超えた効果 |

通常、制約なしで取得できるのは強度4まで。

強度5以上には相応の制約・代償・誓約などが必要。

### 攻撃

1：牽制程度  
2：実戦的  
3：一般的な主力攻撃  
4：強力な攻撃  
5：決め技級  
6：厳しい条件下で極めて高い致死性

### 防御

1：軽い攻撃の軽減  
2：通常攻撃への実用的防御  
3：一般的な念攻撃への主力防御  
4：強力な発へ耐える  
5：条件下で非常に高い防御  
6：厳しい条件下でほぼ突破不能

### 強化

1：小さな補助  
2：明確な強化  
3：能力値1段階程度の明確な向上  
4：能力値2段階程度の強力な向上  
5：一分野で常識外れ  
6：条件下で圧倒的

※具体的な能力値加算方法は発ごとにGMと調整する。

### 拘束

1：軽い妨害  
2：一部行動を制限  
3：移動不能など明確な拘束  
4：多くの身体行動を大幅制限  
5：条件下でほぼ完全拘束  
6：厳しい条件下で絶対拘束級

### 操作

1：一瞬の誘導  
2：単純な行動を1回強制  
3：数ラウンドの単純命令  
4：複雑な行動を強制  
5：条件下で意思決定をほぼ支配  
6：厳しい条件下で完全操作

対象自身の生命・信念・重大な利益に反する命令には、より高い強度を必要とする。

### 探知

1：存在の有無  
2：大まかな位置・数  
3：位置・移動の継続把握  
4：詳細な状態や特徴  
5：通常隠しにくい情報まで高精度取得  
6：厳しい条件下で極めて精密な情報取得

記憶・未来などは特殊性も必要。

### 隠蔽

1：少し発見しにくい  
2：通常の凝に対して明確な優位  
3：専門的に探されても見破りにくい  
4：熟練者でも発見困難  
5：条件下で極めて発見困難  
6：厳しい条件下で通常手段ではほぼ発見不能

### 移動

1：軽い移動補助  
2：高速移動・高跳躍  
3：通常困難な立体移動  
4：大幅な高速移動・特殊移動  
5：条件付き瞬間移動級  
6：厳しい条件下で大規模な空間移動

瞬間移動などは別途特殊性を要求する場合がある。

### 生成

1：単純な小物  
2：実用品・通常武器  
3：高性能な道具・戦闘用具  
4：大型・複雑・非常に高性能  
5：条件下で極めて特殊  
6：通常では成立しない規模・性能

生成物そのものとは別の特殊能力を持つ場合、その能力分の構築が必要。

### 妨害

1：軽い不利  
2：特定判定に-1程度  
3：複数の関連行動に明確な不利  
4：戦闘能力を大きく低下  
5：条件下で能力を著しく制限  
6：厳しい条件下で特定能力をほぼ封殺

発そのものを封印するなどの場合は特殊性も必要。

### 特殊

特殊効果そのものの強力さ・自由度・確実性を表す。

特殊性とは別に判定する。

## 発の構築値

出典：Ver.0.2 第16節。

基本式：

**構築値＝強度＋射程＋範囲＋持続＋特殊性＋系統適性**

柔軟性は構築値に含めない。

|---|---:|
| 自分 | +0 |
| 接触 | +0 |
| 近距離 | +1 |
| 中距離 | +2 |
| 長距離 | +3 |
| 超遠距離 | +4以上 |

## 対象・範囲

<a id="sec-19"></a>

## 持続

出典：Ver.0.2 第19節。

| 持続 | 構築値 |
|---|---:|
| 1ラウンドまで | +0 |
| 2～5ラウンド | +1 |
| 1シーン | +2 |
| 数時間 | +3 |
| 1日以上 | +4以上 |

「瞬間」という曖昧な表現は使用せず、1ラウンド以内を基準とする。


<a id="sec-20"></a>

## 特殊性

出典：Ver.0.2 第20節。

特殊性は「珍しさ」ではなく、**通常ルールをどれだけ飛び越えるか**で判断する。

| 特殊性 | 基準 |
|---:|---|
| +0 | 通常カテゴリで処理可能 |
| +1 | 通常効果へ小さな特殊ルールを追加 |
| +2 | 本来取得できない情報・状態へ干渉 |
| +3 | 念能力・空間などシステム根幹へ干渉 |
| +4 | 時間・因果など通常ルールを大きく覆す |

例：

+0：
攻撃、通常拘束、身体強化、通常探知、通常治療など。

+1：
マーキング、特定条件のみを識別する探知など。

+2：
記憶読取、強制絶、限定的瞬間移動など。

+3：
発の封印、能力コピー、異空間生成、限定的未来予知など。

+4：
非常に強力な予知、広範囲な能力コピー、因果干渉など。

特殊性が高いだけで自動的に許可されるわけではなく、内容によって制約等を要求する。


<a id="sec-21"></a>

## 複合発

出典：Ver.0.2 第21節。

複数の効果を持つ発は、以下の3種類に分ける。

#### 自然な応用

同一の能力原理から自然に生じる用途。

**追加構築値なし。**

#### 選択式副効果

一度の使用では、主効果か副効果のどちらかしか発生しない。

追加構築値：

**副効果強度÷2、端数切り上げ**

#### 同時発生副効果

一度の成功で、主効果と副効果が同時に発生する。

追加構築値：

**副効果強度をそのまま加算**

射程・範囲・持続が共通なら二重計上しない。

副効果だけ異なる性能を持つ場合は差額を追加する。

特殊性・系統適性は必要に応じて別途加算する。


<a id="sec-22"></a>

## 制約・代償・誓約

出典：Ver.0.2 第22節。

これらは**構築値を安くするための点数ではない。**

通常では成立しない性能を成立させる根拠として扱う。

#### 発動条件

能力使用に必要な手順・条件。

#### 制約

使用機会・対象・状況を狭める。

#### 代償

使用時または使用後に必ず受ける不利益。

#### 誓約

自ら定めたルール。

破ること自体は可能だが、破った場合に重大な結果を受ける。

### 重さの目安

#### 1：軽い

ほぼ困らない。

例：
能力名を叫ぶ、決まったポーズを取る。

強度5以上の根拠には基本的にならない。

#### 2：明確な不便

実戦で時々困る。

例：
両手が必要、主行動1回の準備が必要。

#### 3：大きな制限

戦術へ明確な影響。

例：
特定条件の対象のみ、戦闘中1回、1ラウンド準備など。

強度5を成立させる有力な根拠。

#### 4：非常に重い

戦い方自体を縛る。

例：
特定人物にしか使えない、使用後重傷、誓約違反で発を永久喪失。

#### 5：極端

生命・念能力・人生そのものを危険にさらす。

例：
誓約違反で死亡、一生に一度、使用後念能力を永久喪失。

強度6など通常限界を超える能力の根拠。

軽い条件を大量に重ねても、高い制約とは評価しない。

実際のゲーム上の不便・危険を評価する。

#### 強度との関係

強度1～4：
原則として制約なしでも取得可能。

強度5：
原則、重さ3以上相当の条件が必要。

強度6：
原則、重さ4～5相当の非常に重い条件が必要。

ただし機械的な交換レートではなく、能力内容との釣り合いをGMが判断する。


<a id="sec-23"></a>

## 発のオーラ消費

出典：Ver.0.2 第23節。

基本値：

**強度＋実際に使用した射程＋実際に使用した範囲**

最大性能ではなく、その使用で実際に使った性能を計算する。


<a id="sec-24"></a>

## 1ラウンド型と持続型

出典：Ver.0.2 第24節。

#### 1ラウンド以内

基本値を**現在オーラから消費**する。

#### 2～5ラウンド

基本値を**拘束オーラ**へ移す。

#### 1シーン

**基本値＋1**を拘束。

#### 数時間

**基本値＋2**を拘束。

#### 1日以上

**基本値＋3以上**を拘束。

持続型の発を解除すると、拘束オーラは現在オーラへ戻る。

複数の持続発を同時に使用した場合、拘束量は合計する。

必要な現在オーラを確保できない場合、その発は開始できない。

現在オーラが0になっても、すでに拘束されているオーラによる持続発は自動解除されない。

発を解除すれば、拘束オーラを現在オーラへ戻すことができる。

規模を途中で変更した場合、その時点の実際の性能へ拘束量を調整する。

毎ラウンド新しい攻撃・治療等を発生させる能力は、単に「存在を維持する」能力とは別に、追加消費等をGMが設定する。


<a id="sec-25"></a>

## 治療系の発

出典：Ver.0.2 第25節。

治療は通常の発より重い。

基本消費：

**治療強度＋1＋射程＋対象補正**

| 強度 | 治療可能範囲 | 接触・単体消費 |
|---:|---|---:|
| 1 | 止血・痛み軽減 | 2 |
| 2 | 軽傷 | 3 |
| 3 | 負傷 | 4 |
| 4 | 重傷 | 5 |
| 5 | 瀕死 | 6 |
| 6 | 通常困難な重大損傷 | 7以上 |

強度2以上による通常治療では、原則として**1回につき負傷点1点回復**。

強度が高いほど回復量が増えるのではなく、**治療できる負傷の重さが上がる。**

例：

重傷3点へ強度4治療を使用。

3 → 2

さらに使用すると、

2 → 1

となる。

#### 瀕死

強度5なら、

- 瀕死・危険 → 瀕死・安定
- 安定済みの瀕死者へ使用 → 負傷点4→3

が可能。

#### 致命傷

強度5で生命を安定させることは可能。

致命的な損傷そのものを完全治療するには、原則として強度6が必要。

#### 強度6

欠損、重大な臓器損傷など、通常では治療困難な損傷を扱う。

相応の制約・代償・誓約等を必要とする。

死者蘇生は通常の治療発では不可。

治療発は同じ傷へ複数回使用可能。

そのたびに通常通りオーラを消費する。
