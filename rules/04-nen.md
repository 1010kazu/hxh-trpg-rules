# 第4章 念

最大オーラ・現在オーラ・拘束オーラは資源の点数。攻撃・防御・その他の「段階」は出力の配分であり、資源とは別に管理する。[戦闘](07-combat.md)と合わせて読む。

## 採用ルールの運用

<a id="a05"></a>

**暫定補足 A05：資源の上限。** 常に現在オーラ+拘束オーラ≦最大オーラ、各値0以上を保つ。回復できる現在オーラの上限は最大−拘束。消費は現在だけを減らし、拘束は現在から拘束へ移す。解除・持続満了では拘束から現在へ戻す。拘束分を直接消費できない。現在0では新たな発・練・堅・硬を開始できない。最後の点を支払って成立した練・堅は、その有効期間まで維持でき、次の維持時点で不足していれば終了する。成立済みの持続発は現在0だけでは解除しない。

<a id="a06"></a>

**暫定補足 A06：その他の使用枠。** 隠・周はそれぞれその他1段階を占有し、複数物体への周は物体ごとに1段階。占有分は同時には共有できない。必要段階を割り当てられなくなった場合、使用者が維持する技術を選び、実際の配分変更と同時に維持不能な技術を終了する。発は自動ではその他枠を使わず、必要な発だけ設計時に指定する。その他段階だけで未定義の数値ボーナスは得ない。

<a id="a07"></a>

**暫定補足 A07：念技術のタイミング。** 絶・隠・周・堅・練はそれぞれ補助行動で開始する。1回の補助行動で複数の技術は開始できない。絶・隠・周・練の任意解除は自分の手番中に行動不要で行える。解除しても使用済みの行動と消費は戻らない。絶中は念配分と念由来の攻防補正を使えず、発・他の能動的念技術を使えない。絶開始時には既存の能動的念技術と持続発を解除する。絶による技術終了・拘束返還・絶への移行は一連の切替とし、途中で返還分を他の技術へ使えない。自分の手番に絶を行動不要で解除すると直ちに纏へ戻り、未使用の行動は使える。円は探索中の主行動（通常は1回の調査行動）として感覚+念技術で索敵し、距離と難易度は実行前にGMと合意する。射程を広げるだけで自動成功や壁越しの精密情報は得ない。

<a id="a08"></a>

**暫定補足 A08：流・練・堅・硬の併用。** 流は自分の手番に1回、行動不要で行える。敵行動への流は攻撃宣言後、判定前にリアクションで行う。堅の7段階を扱う場合も、一度の流で移動できる量は表にある5段階までとし、6段階以上の移動は別の使用機会に分ける。堅開始時と維持終了時は、総量を満たすようその場で配分を決め直す（変更不能中を除く）。堅の任意終了は自分の手番開始時、維持消費の前に行う。練は補助行動で開始し、重複せず次の自分の手番開始で切れる。追加2段階は選んだ区分に留まり、流で移せない。堅と練は併用可。ただし練の追加分を除いた堅の7段階内で防御4以上を満たす。硬では必要なその他の占有を残し、残りの使用可能な段階をすべて集中する。4段階以上の集中が必要。堅は終了し、その追加段階は使えない。練の追加段階は硬への集中に使える。硬には流の判定は不要。次の自分の手番開始まで配分を固定し、その時点で占有条件を満たすよう配分を戻す。練が先に終了した場合は追加2段階だけが消え、残りの配分固定は続く。拘束オーラがあること自体は硬の禁止条件にならない。堅を再開するなら開始費と補助行動が必要。

<a id="a09"></a>

**暫定補足 A09：凝と隠の情報。** 隠を開始・維持する者に対し、観察可能な相手はラウンドごとに1回、隠の配分情報が必要になった時点で行動不要の凝対抗を行える。凝成功は観察者ごと・ラウンドごとに記録する。成功者が観察可能な間は同ラウンドの後続の流も追える。味方への報告はその時点の情報で、受け手の凝成功や以後の自動追跡にはならない。次ラウンドは再対抗する。非公開の配分は紙やGMへの個別連絡で先に確定する。通常の凝で発の全性能や誓約までは判明しない。

<a id="a10"></a>

**暫定補足 A10：未記載の系統適性。** 以下の系統表で具現化→操作、操作→具現化の補正は原文に記載がないため、両方向+2を本作の補完値として採用する。

<a id="sec-7"></a>

## 念

出典：Ver.0.2 第7節。

念能力者は以下を持つ。

- 最大オーラ
- 現在オーラ
- 拘束オーラ
- 念技術
- 念系統
- 発


<a id="sec-8"></a>

## オーラ量

出典：Ver.0.2 第8節。

**最大オーラ＝10＋精神×3**

現在オーラは、その時点で自由に使用できるオーラ。

拘束オーラは、持続型の発などを維持するため一時的に使用不能となっているオーラ。


<a id="sec-9"></a>

## 念技術

出典：Ver.0.2 第9節。

念技術は1～6。

初期値は**3**。

| 値 | 目安 |
|---:|---|
| 1 | 初歩 |
| 2 | 未熟 |
| 3 | 一般的な念能力者 |
| 4 | 熟練 |
| 5 | 一流 |
| 6 | 卓越 |

念技術は、

- 念判定
- 発の威力
- 拘束・操作
- 念への抵抗
- 発容量

などに影響する。


<a id="sec-10"></a>

## 念系統

出典：Ver.0.2 第10節。

念系統は、

- 強化系
- 変化系
- 放出系
- 具現化系
- 操作系
- 特質系

の6種類。

1D6によるランダム決定も可能。

### 系統適性

通常5系統は原作の六性図を基準とする。

- 自系統：+0
- 隣接系統：+1
- 2つ離れた系統：+2
- 最も不得意な系統：+3

#### 対応

**強化系**
- 強化 +0
- 変化・放出 +1
- 具現化・操作 +2

**変化系**
- 変化 +0
- 強化・具現化 +1
- 放出 +2
- 操作 +3

**放出系**
- 放出 +0
- 強化・操作 +1
- 変化 +2
- 具現化 +3

**具現化系**
- 具現化 +0
- 変化 +1
- 強化 +2
- 放出 +3
- 操作 +2

**操作系**
- 操作 +0
- 放出 +1
- 強化 +2
- 変化 +3
- 具現化 +2

#### 特質系

特質系は特殊な系統として扱う。

特質系PCは、

- 特質 +0
- 強化 +1
- 変化 +1
- 放出 +1
- 具現化 +1
- 操作 +1

とする。

つまり、他の5系統すべてを準得意として扱える。

非特質系PCは、原則として特質系能力を取得できない。

#### 複数系統を使う発

発で使用している**念系統ごとに1回ずつ**系統補正を加える。

同じ系統を一つの発の中で複数用途に使っても、補正は重複しない。

不得意系統を使用しても、発の強度そのものを下げることはしない。

代わりに、構築値が増加して発容量を圧迫する。適性補正を実使用オーラの消費へ再加算しない。特質系も効果カテゴリ・能力原理・特殊性の評価を行う。


<a id="sec-11"></a>

## 基礎念技術

出典：Ver.0.2 第11節。

### 纏

通常の念状態。

原則として常時維持されているものとする。

### 絶

オーラを閉じ、気配を消す。

探索・隠密などに有効。

絶の間は念による防御をほぼ失う。

### 練

瞬間的に通常以上のオーラを出力する。

**現在オーラ2点を消費。**

次の自分の手番開始まで、

**攻撃・防御・その他のいずれか一つへ、追加で+2段階のオーラを配分する。**

通常5段階の配分を一時的に超えることができる。

### 凝

能動的に周囲の念・異常を注意深く観察する場合は主行動。

相手が隠を使用した場合のみ、行動消費なしで直接対抗できる。

凝：

**2D6＋感覚＋念技術**

隠：

**2D6＋精神＋念技術**

凝側が勝利した場合、そのラウンド中は隠を見破る。

そのラウンド中に後から行われた流によるオーラ移動も確認できる。

次ラウンドになると、再び隠の効果が有効になる。

### 隠

補助行動で開始。

維持中は、その他オーラ1段階を固定して使用する。

通常公開情報であるオーラ配分と流による移動を隠す。

発による隠蔽強化については、発の「隠蔽」カテゴリで処理する。

### 円

探索・索敵用。戦闘中も主行動で単発の索敵ができる。使用前に目的・距離・難易度を確認し、2D6＋感覚＋念技術で判定する。成功情報の範囲はGMが条件から示す。継続的な自動索敵、隠の自動無効化、詳細な能力の把握や戦闘補正は自動で得られない。

### 流

戦闘中のオーラ配分変更。

1段階分のオーラ移動は自動成功。

2段階以上を一度に動かす場合、

**2D6＋俊敏＋念技術**

を使用。

目標値：

| 移動量 | 目標値 |
|---:|---:|
| 2段階 | 10 |
| 3段階 | 12 |
| 4段階 | 14 |
| 5段階 | 16 |

「移動量」は、実際に移動したオーラ点数で数える。

例：

2/2/1 → 4/1/0 は2点を移動しているため、2段階変更。

通常失敗の場合でも、宣言した変更のうち合法な1段階だけは変更できる。リアクションは失敗・ファンブルでも消費する。

ファンブルの場合は変更できない。

敵の行動に対応して流を使用する場合はリアクションを消費する。

### 周

補助行動で開始。

物体をオーラで覆い、念戦闘に耐えられる状態にする。

基本的に**その他オーラ1段階**を使用する。

周を施した武器は攻撃威力+1、周を施した防御物は防護値+1を暫定値とする。

同じ攻撃・被攻撃に複数の周が適用できても、同種の周補正は最大+1。防御物はその攻撃を実際に防げる位置・範囲で使う。周の威力+1は、同じ攻撃の硬の威力補正と重複して加算しない。

硬で武器へ集中する場合、周はその武器を硬の焦点として使用可能にする役割を持つ。

通常の物体を周なしで極端な念攻撃に使用した場合、GM判断で破損することがある。

細かな耐久値管理は行わない。

### 堅

全身を高出力の念で守り続ける。

補助行動で開始し、開始時に**現在オーラ2点を消費**。開始手番に維持費は重ねず、初回の維持判断は次の自分の手番開始に行う。

以降、維持する場合は自分の手番開始時に**現在オーラ1点を消費**。

堅の間は、通常5段階のオーラ配分が**合計7段階**になる。

ただし、

**防御オーラを最低4段階**

維持しなければならない。

### 硬

主行動による攻撃等に付随して使用。

必要なその他枠を残し、堅の追加段階を除いた残り全部を攻撃へ集中する。集中4段階で最終威力+1、5～7段階で+2。4段階未満では使用できない。練による追加段階も集中に使える。

硬使用時に堅は終了する。防御0となり、次の自分の手番開始まで流を含め配分を変更できない。練の満了による追加段階の消失は配分変更に数えない。

通常近接では集中段階を攻撃オーラとして計上し、硬の補正を1回加える。発では元の発威力に硬の補正だけを加え、攻撃オーラを重ねない。同じ打撃の通常近接と発は高い基礎威力1つを使い、硬の補正も1回だけ適用する。周付き武器を硬の焦点として維持できるが、周の威力+1は重ねない。
