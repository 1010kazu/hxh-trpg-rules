# LT：TRPG制作 × ハーネスエンジニアリング

[PDF版](slides.pdf)も同梱。投影用HTMLからChromiumで生成した。

5分・全8枚。技術者向けに、TRPGの予備知識なしで制作の仕組みを紹介する。[投影用スライド](index.html)をブラウザで開く。外部ライブラリ・通信・ビルドは不要。左右キー・Space・画面下のボタンで移動し、「全画面」で投影する。ブラウザの印刷から横向き・背景グラフィック有効でPDF保存できる。

制作資料としてGitHubで管理し、ルール閲覧サイトの掲載対象には追加しない。プロジェクトの状況は制作時点のリポジトリの記録に基づく。「ハーネス」はこの制作環境を説明するための呼び方であり、外部の標準定義を引用したものではない。

## 発表原稿と時間配分

合計300秒。時間は目安で、話速を測ったリハーサルは未実施。

### 1：念能力を自由に作るために、AIの仕事に枠を作る（0:00〜0:25 / 25秒）

HUNTER×HUNTERの非公式TRPGを、AIと作っています。自分だけの念能力を設計して、探索や交渉、戦闘を楽しむゲームです。今日はゲームのルールよりも、その制作環境の話です。AIがルールを書き、確かめ、遊んで、見直す。その一周を支える仕組みを、ハーネスエンジニアリングとして紹介します。

### 2：「好きな能力を作れる」は、ルールを作る側には難しい（0:25〜1:00 / 35秒）

TRPGは、会話とダイスなどの判定で物語を進めるゲームです。このシステムでは能力を自由に設計できます。ただ、自由さを支える処理は複雑です。同じ能力の工夫なのか、別の効果を買い足すのか。届く距離、行動回数、消費、持続がどう組み合わさるのか。個別の文章が自然でも、組み合わせて遊ぶと曖昧さが出ます。そこで、裁定の一貫性を保つ制作環境が必要になりました。

### 3：ハーネス＝AIが作業を進めるための環境（1:00〜1:35 / 35秒）

この発表では、ハーネスをAIが作業を進めるための環境という意味で使います。何を読んで、どこまで変えてよく、何を確認したら次へ進めるのか。これを依頼のたびに説明する代わりに、リポジトリに置きます。指示と制約、参照する正本、検証と記録がセットです。特別な基盤ではなく、MarkdownとPythonとGitHubで組んでいます。

### 4：「変えてよい」を明文化する（1:35〜2:15 / 40秒）

まず変更の権限を分けました。表現の整理や例示はAIが進められます。不足する処理は、暫定補足と明示して追加します。一方、既存の数値や設計方針は、Issueで理由と影響を記録し、人間と相談して採用します。保存原文は固定し、実際に遊ぶための本文を別に持ちます。AGENTS.mdに方針、制作スキルに判断の手掛かり、運用ガイドに手順を置いて、毎回同じ基準に戻れるようにしています。

### 5：確かめ方を、3つに分ける（2:15〜3:00 / 45秒）

検証も分けます。機械は、原文ハッシュ、55節の対応先、リンク、サンプル数値など、繰り返せる整合性確認を担当します。AIは境界ケースや導入シナリオを遊び、行動の選択と裁定をします。行動や補正を宣言してから、ツールでダイスを振り、計算と状態変化を残します。ただし、これで楽しさまで確認したことにはしません。人間の実卓はまだ未実施です。この3つを同じ検証済みという言葉にまとめないようにしています。

### 6：試遊の成果は、「要調整」を持ち帰れたこと（3:00〜3:45 / 45秒）

初回のAI試遊では、同じ部屋と移動区画の距離区分が曖昧だと分かりました。ゲームを進めるには判断が必要ですが、その場の仮裁定を正式なルールにしてはいけません。そこで、試遊ログに課題T01として残し、距離を扱う暫定補足A12のIssueに統合しました。試遊から課題へ、課題から合意、本文への反映、再検証へ戻す流れです。この例は解決済みという話ではなく、曖昧さを検討可能な形で持ち帰れた例です。

### 7：確認できたことと、まだ言えないことを分ける（3:45〜4:25 / 40秒）

現状、本文とサンプルの機械検証、試遊の記録、push時のCIは用意できています。一方で、AI試遊の結論は要調整です。同じAIがGMとプレイヤーを担当するため、秘密の情報を完全に隔離できるわけでもありません。人間が理解できるか、楽しいか、全体のバランスがよいかは今後の課題です。ハーネスの効果として説明したいのは、確認した範囲と残る課題を追えることです。

### 8：自由なルール制作を、検証できる仕事にする（4:25〜5:00 / 35秒）

この制作での学びは、AIに依頼文と一緒に、正本、変更権限、確かめ方、問題が出たときの戻し先を渡すことです。自由なアイデアを、レビューして見直せる仕事にしていく。その組み合わせが、TRPG制作のハーネスになっています。リポジトリは公開しています。非公式の二次創作として、原作への敬意と権利表記も含めて運用しています。ありがとうございました。
