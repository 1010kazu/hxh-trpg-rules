## 進行記録

行動・対象・対応を決めてから振る。ダイスは乱数ツール、判断と裁定はAI。出目を選び直さない。対抗の両側、特殊出目、使用した補正、消費時点を残す。長い会話は選択理由と得られた情報を要約する。

| | | | |

必要な裁定を本文から得られなければ記録する。仮裁定はその内容と理由を明示し、以降の結果が仮裁定に依存することを示す。進行不能なら停止地点と未検証部分を残す。結末・回復・成長・チェック消去まで記録する。
